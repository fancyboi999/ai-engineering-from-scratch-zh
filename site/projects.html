项目 · 从简单到进阶

构建真正有人用的工具。

每个项目把课程知识变成可运行产物：报告生成器、记忆服务器、任务队列或 agent。你逐阶段构建，评分器检查每个阶段，导师陪你完成。

开始第一个项目 提交你的项目
怎样学习

三条命令，一个项目

按任务选择 Python、Rust、TypeScript 或 Go。核心测试离线运行；可选框架实验单独列出依赖。

  1. 01

    创建工作区

    复制初始文件。每个待实现函数都给出了精确签名。

    python3 scripts/project_test.py research-report-agent --init my-report-agent
  2. 02

    运行评分器

    一次构建一个阶段。评分器检查当前工作及所有先前阶段。

    python3 scripts/project_test.py research-report-agent --stage 1 --path my-report-agent
  3. 03

    跟随导师学习

    需要指导？在 Claude Code 中逐阶段学习，获得提示和反馈。

    /build-project research-report-agent
进阶阶梯

选择难度

五个级别，每级增加一种新的工程挑战。新项目编写或提交后加入对应级别。

社区

做出了有用的工具？把它加入阶梯。

社区项目与核心项目使用相同结构：project.json，包含课程、初始实现和测试的各阶段，以及参考解。项目在此展示并附上你的 GitHub 账号。

  • 交付真实产物，而非聊天演示
  • 每阶段都有无需 API key、离线通过的测试
  • 独立评估 fixture，明确分数能证明什么、不能证明什么
  • 原创实现，附官方规范和研究链接

复制后，先将 projects/my-project/project.json 中的 id 设为 my-project，再运行评分器。

cp -r projects/_template projects/my-project
python3 scripts/project_test.py my-project \
  --all --solution --strict
