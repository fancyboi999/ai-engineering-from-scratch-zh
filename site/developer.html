AI Engineering from Scratch

开发者资源

这是 AI Engineering from Scratch 中文版的机器可读入口。项目是一套静态开源课程，不是托管应用 API。Agent 和开发工具应从 llms.txt 开始；它把课程映射到 canonical 页面和原始 Markdown 来源。

稳定资源

  • /llms.txt 是面向 agent 的课程地图。
  • /sitemap.xml 列出 canonical 公开 URL。
  • /openapi.json 描述只读资源接口。
  • /catalog.html 是面向学习者的可搜索目录。
  • GitHub 是课程、代码、quiz 和可复用产物的事实来源。

Markdown 内容协商

首页或主要导航路由收到带 Accept: text/markdown 的请求时，会返回 agent 地图，并设置 Content-Type: text/markdown。响应按 Accept 区分，避免缓存混用 HTML 和 Markdown 表示。

MCP 状态

本站目前不提供托管 MCP server 或需要认证的产品 API。课程会教你构建和运维 MCP server，相关课程产物保存在仓库中。若要提供远程 Streamable HTTP MCP endpoint，需要另行确定产品范围、认证策略和运维负责人。
