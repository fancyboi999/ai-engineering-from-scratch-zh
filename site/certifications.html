Model Context Protocol Associate

Model Context Protocol Associate: 证明你理解 Model Context Protocol 的工作方式：宿主、客户端、服务端与工具，连接它们的消息流和原语，以及保障连接安全的信任边界。 面向需要把 agent 连接到外部系统，并理解协议工作方式及组件通信机制的 AI 工程师、平台工程…

  • MCPA 蓝图是学习预算，不是核对清单
  • 阅读 MCP 规范
  • MCP 解决的集成难题
  • JSON-RPC 信封
  • MCP 的无状态核心
  • 区分现代 MCP 服务端与旧版服务端
  • Host、客户端与服务端：MCP 的进程拓扑
  • 发现服务端并协商其能力
  • 工具定义中的契约
  • 像审查者一样阅读服务器清单
  • 模型交互流程
  • Tools primitive：调用操作并读取结果
  • Resources：无状态服务器中的可寻址内容
  • Prompt 模板与参数补全
  • 多轮请求与信息征询
  • 已弃用，不等于已移除：Roots、Sampling 与 Logging
  • 订阅流：通知、进度与取消
  • 工具调用生命周期
  • 请求失败的两种方式
  • 传输方式与 HTTP Header 契约
  • 缓存新鲜度与基于 Cursor 的分页
  • 长时间运行的工作与 Tasks Extension
  • MCP 交互中的信任区域
  • 为 MCP Server 授权访问
  • 向 Authorization Server 证明 Client 身份
  • 同意与最小权限
  • MCP 工具调用的风险与安全控制
  • 用一个 Trace ID 连接可审计性与可观测性
  • 每个 MUST 都需要负责人
  • 为任务选择合适的 MCP 形态

学习方法

学习。动手。在压力下做决策。

01

理解机制

理解考试蓝图背后的概念，而不是死记产品术语。

02

构建系统

用实验和产物把架构、工具、评估与安全决策落到实处。

03

练习判断

通过原创场景题、限时模拟和分域反馈，找到自己的决策薄弱点。
