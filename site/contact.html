选择合适的渠道

已发布的课程、代码示例、quiz、翻译或站点功能有误，或无法按文档使用时，请提交 issue。需要理解概念、比较学习方法，或者想法仍需社区讨论时，请使用 discussion。公开讨论能让遇到同样问题的学习者检索到答案。

本课程不提供学习者账号、付费报名、招生或官方认证服务。维护者会在时间允许时处理公开反馈，不承诺回复时限。请提供具体标题、URL、命令、环境和实际结果，帮助我们复现并解决问题。

负责任地报告

不要在 issue 中发布密钥、私人学习数据或凭据。如果问题涉及安全漏洞，请通过仓库的私有 GitHub Security Advisory 报告。普通内容、无障碍、课程或站点问题，请附上 URL、预期行为、实际行为和最小复现。
