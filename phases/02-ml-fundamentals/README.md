# 阶段 2：机器学习基础

> 经典机器学习仍是多数生产级 AI 的骨架。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 1 的数学基础和 NumPy。用 `python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route ml-foundations` 检查这条学习路径。

**第一课：** [什么是机器学习](01-what-is-machine-learning/)

从仓库根目录运行：

```bash
python3 phases/02-ml-fundamentals/01-what-is-machine-learning/code/ml_intro.py
```

记录命令、退出码、测试准确率、随机基线，以及一句解释：为什么训练出的分类器优于这个基线。

**下一步：** 改变类别之间的间隔，预测准确率如何变化，重新运行，然后继续学习[从零实现线性回归](02-linear-regression/)。
