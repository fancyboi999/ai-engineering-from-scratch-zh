# SVM 核函数选择指南

SVM 由两个选择决定：核函数（决定决策边界的形状）和正则化参数（控制间隔宽度与分类错误之间的权衡）。这两项选对与否，决定了模型是毫无用处还是表现强劲。

## 决策清单

1. 数据是线性可分的（或接近线性可分）吗？
   - 是：用线性核。它更快，也更好解释。
   - 否：进入第 2 步。

2. 特征数与样本数之比如何？
   - 特征数 >> 样本数（例如用 TF-IDF 的文本）：用线性核。高维数据往往线性可分，RBF 只会徒增复杂度。
   - 样本数 >> 特征数（例如有 10-50 个特征的表格数据）：默认选 RBF 核。

3. 预期决策边界是光滑的吗？
   - 光滑、连续的边界：RBF 核
   - 多项式形状的边界：多项式核（从 2 次或 3 次开始）
   - 领域知识提示存在特定的交互项：用次数匹配的多项式核

4. 数据集有多大？
   - 少于 10,000 个样本：哪种核都行，RBF 是稳妥的默认选择
   - 10,000 到 100,000 个：用线性核或 LinearSVC（原问题形式，每个 epoch O(n)）
   - 超过 100,000 个：不要用核 SVM。换成线性 SVM、梯度提升或神经网络。

5. 做特征缩放了吗？
   - SVM 必须做特征缩放。拟合之前一律标准化（零均值、单位方差）。未缩放的特征会扭曲间隔的几何形状。

## 核函数选择流程图

```
Start
  |
  v
Features > 1000 or features >> samples?
  Yes --> Linear kernel (LinearSVC for speed)
  No  --> Dataset < 10k samples?
            Yes --> Try RBF first (best general-purpose kernel)
            No  --> Linear kernel (kernel SVMs are O(n^2) to O(n^3))
```

如果 RBF 效果不好，试试 2-3 次的多项式核。如果还不行，这个问题可能不适合用 SVM。

## 调 C（正则化）

C 控制误分类的惩罚力度。它与正则化强度成反比。

| C 值 | 效果 | 适用场景 |
|---------|--------|-------------|
| 0.001 - 0.01 | 间隔宽，允许较多违例 | 数据有噪声，看重泛化 |
| 0.1 - 1.0 | 均衡 | 不错的起始范围 |
| 10 - 1000 | 间隔窄，违例少 | 数据干净，需要高准确率 |

调参策略：
- 从 C=1.0 开始
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 用交叉验证选出最佳值
- 如果最佳 C 落在搜索范围的边缘，就朝那个方向扩大范围

## 调 gamma（RBF 核）

gamma 控制单个训练点的影响范围有多远。它决定了高斯函数的宽度。

| gamma 值 | 效果 | 适用场景 |
|-------------|--------|-------------|
| 小（0.001） | 每个点影响很大的区域。边界光滑、简单 | 欠拟合或特征很少 |
| 中（auto：1/n_features） | sklearn 默认值。合理的起点 | 一般用途 |
| 大（10+） | 每个点只影响附近的点。边界复杂、弯弯曲曲 | 有过拟合风险 |

调参策略：
- 从 gamma="scale" 开始（1 / (n_features * X.var())，sklearn 默认值）
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10]
- 低 gamma + 高 C 容易过拟合
- 高 gamma + 低 C 容易欠拟合

## 联合调 C 和 gamma

C 和 gamma 相互影响。一律一起调，不要分开调。

推荐做法：
1. 粗网格搜索：C 取 [0.01, 0.1, 1, 10, 100]，gamma 取 [0.001, 0.01, 0.1, 1, 10]（25 种组合）
2. 找到最佳区域
3. 在最佳区域附近做细网格搜索（例如 C 取 [5, 10, 20, 50]，gamma 取 [0.05, 0.1, 0.2]）
4. 全程使用 5 折交叉验证

## 常见错误

- 在高维稀疏数据上用 RBF 核（线性核更好，且快 100 倍）
- 忘了缩放特征（SVM 最常见的单一错误）
- 在有噪声的数据上把 C 设得太高（记住了噪声，而不是学到边界）
- 在超过 5 万个样本的数据集上用核 SVM（训练时间高得难以接受）
- 不把 C 和 gamma 放在一起调（它们会相互补偿）
- 默认用 5 次以上的多项式核（过拟合严重，先试 2 或 3 次）

## 速查

| 核函数 | 适用场景 | 关键参数 | 训练复杂度 |
|--------|------------|----------------|-------------------|
| 线性 | 文本/TF-IDF、特征多、数据量大 | 只有 C | 每个 epoch O(n) |
| RBF | 通用，少于 1 万个样本 | C、gamma | O(n^2) 到 O(n^3) |
| 多项式 | 已知存在多项式关系 | C、degree、coef0 | O(n^2) 到 O(n^3) |
| Sigmoid | 很少有用（相当于两层神经网络） | C、gamma、coef0 | O(n^2) 到 O(n^3) |
