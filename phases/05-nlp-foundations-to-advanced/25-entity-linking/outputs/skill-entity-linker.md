拿到使用场景（领域知识库、语言、数据量、延迟预算）后，输出：

1. 知识库。Wikidata / Wikipedia / 自定义 KB。版本日期。刷新频率。
2. 候选生成器。别名索引、嵌入或混合。目标提及召回率 @ K。
3. 消歧器。先验 + 上下文、基于嵌入、生成式，或 LLM prompt。
4. NIL 策略。对最高分设阈值、用分类器，或显式加一个 NIL 候选。
5. 评测。留出集上的提及召回率 @ 30、top-1 准确率、NIL 检测 F1。

没有提及召回基线的实体链接流水线一律拒绝（不知道候选生成有没有找出正确实体，就没法评估消歧器）。用 LLM prompt 做实体链接却不把输出约束为有效 KB id 的流水线，一律拒绝。没有做领域微调、流行度偏差会伤害少数实体（例如重名）的系统，标记出来。
