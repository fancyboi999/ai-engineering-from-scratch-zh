## 在 GitHub 上开始本阶段

**第一课：** [线性代数直觉](01-linear-algebra-intuition/)

从仓库根目录运行：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

记录命令、退出码、归一化向量输出、投影残差，以及一句解释：为什么矩阵乘向量就是神经网络的一层。

**下一步：** 改一个输入向量，先预测结果，再运行一次；然后继续学习[向量、矩阵与运算](02-vectors-matrices-operations/)。
