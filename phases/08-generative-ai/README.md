# 阶段 8：生成式 AI

> 创作图像、视频、音频、3D 等内容。

## 在 GitHub 上开始本阶段

**前置要求：** 阶段 2“机器学习基础”、阶段 3“深度学习核心”以及阶段 7 第 14 课“从零构建 Transformer”。

**第一课：** [生成模型的分类与历史](01-generative-models-taxonomy-history/)

从仓库根目录运行：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

记录命令、退出码、密度估计、生成的样本，以及一句解释：隐式生成器无法回答有关 `p(x)` 的什么问题。

**下一步：** 改变随机种子，比较密度估计，然后继续学习[自编码器与 VAE](02-autoencoders-vae/)。

浏览[阶段 8 的完整课程列表](../../README.md#phase-8)或[跨阶段路线图](../../ROADMAP.md)。
