给定自己编写并带调试信息编译的程序、该构建的反汇编列表，以及先前分析的静态结论列表，执行一次调试并保存会话文本，为每个结论在每个停止生成一条证据记录。可在 Claude、Cursor、Codex、OpenClaw、Hermes 或任何能读取 SKILL.md 的 agent 中使用本技能。

## 必需输入

- 源码、准确编译命令及生成的二进制。只调试自己构建的程序。
- 该二进制的 `llvm-objdump -d` 或 `objdump -d` 列表，使断点地址来自列表而非记忆。
- 结论涉及结构体类型的 DWARF 转储，或 `ctypes` 布局，作为字段偏移来源。
- 待检验结论，每项为一句话，含函数、寄存器或地址、预期值或边，以及来源课程或文档。
- 调试器：macOS 使用 Command Line Tools 或 Xcode 的 lldb，Linux 使用 lldb 或 gdb。记录版本字符串。

## 步骤

1. 读取列表。对结论中的每个函数记录起止地址。对包含边结论的函数内每个条件分支，记录分支地址、目标和顺序落下地址。
2. 任何运行之前先把调试命令写入文件：每个函数一条 `breakpoint set -n`，每个分支后继一条 `breakpoint set -a ADDR -s MODULE`；停止钩子读取实参寄存器、第一实参背后的内存、栈帧变量；随后 `run`、所需观察点、固定数量的 `continue`，最后 `breakpoint list` 和 `watchpoint list -v`。
3. 以批处理运行调试器，设置 `settings set interpreter.stop-command-source-on-error false`，避免退出后命令失败结束会话。保存完整输出，头部写明命令行和调试器版本。
4. 将会话解析为停止。每项包含程序计数器、函数、原因、钩子打印的寄存器与内存，以及栈帧变量。钩子输出附到紧随其后的停止报告。
5. 在每个能检验结论的停止判定。寄存器结论将寄存器与栈帧变量比较。字段偏移结论通过 DWARF 偏移解码内存字，与栈帧字段比较。边结论读取函数入口的比较值，检查下一停止是否为提升条件预测的后继。调用边结论在进程退出后统计入口停止。
6. 观察一致写 `confirmed`，不一致写 `refuted`，没有停止能检验写 `not-observed`。说明未观察原因：断点从未命中、观察点从未设置，或进程没有退出。
7. 对同源码的优化构建重复执行。内联位置可能断点已解析但零命中；除非结论本身就是被完整运行反驳的调用边，否则保持 `not-observed`。
8. 无法启动时，记录准确错误。macOS 沙箱 shell 报 `attach failed ((os/kern) invalid address)`，启用加固且没有 `com.apple.security.get-task-allow` 的目标拒绝任务端口。两者都不是程序行为的证据。

## 必需报告

- 编译器、调试器版本、操作系统、各二进制构建选项
- 会话文件名称，以及生成各文件的命令
- 按顺序列出停止，附程序计数器、函数、原因和读取的寄存器
- 各结论的判定、产生判定的停止索引、观察文本
- 运行结束时的断点与观察点命中数
- 进程退出码与标准输出
- 保持 `not-observed` 的结论及各自原因

## 必须拒绝

- 将断点成功解析当作代码执行的证明。
- 将零命中当作函数是死代码的证明。
- 没有 DWARF 或 ABI 规则提供的字段偏移，就经指针读取结构体。
- 在非入口停止比较实参寄存器，此时寄存器可能是遗留值。
- 仅从分支指令而非后继停止判定边结论。
- 对优化构建中常驻寄存器的局部变量设内存观察点，将沉默当作证明。
- 调试非自己构建的二进制，或附加不属于自己的进程。
- 判定后删除会话。会话是证据，判定由它派生。
- 将一个输入的运行结果泛化到所有输入。

## 产出

返回以下各节：

1. 构建：编译器、选项、调试器、使用的列表和 DWARF 文件。
2. 计划：原样命令文件，每个断点地址及其来源。
3. 停止：时间线，每次停止一行。
4. 判定：每个结论一行，包含 confirmed、refuted、not-observed 计数和最终判定。
5. 未观察：没有停止检验的每个结论及原因。
6. 环境事实：二进制签名标志、硬件观察点数量、启动错误。

以第一项被反驳结论结束。若没有，说明停止次数及其确认的结论数。
