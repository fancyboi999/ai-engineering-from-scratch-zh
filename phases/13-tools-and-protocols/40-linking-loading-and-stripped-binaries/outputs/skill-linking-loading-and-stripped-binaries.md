给定自己构建的链接后可执行文件或共享库、其未剥离副本，以及参与链接的目标文件，生成报告：命名每个外部调用的提供方，展示从调用点到加载器写入槽的一条完整路径及算术，说明 `strip` 删除什么、加载器仍需要什么，并对照副本符号表为每种函数查找器和签名评分。可在 Claude、Cursor、Codex、OpenClaw、Hermes 或任何能读取 SKILL.md 的 agent 中使用本技能。

## 必需输入

- 链接后文件、准确链接命令和工具链版本。
- 未剥离副本，或 `strip` 前的文件，作为函数起点和名称的真值。
- 参与链接的可重定位目标文件及其重定位记录，用于签名和链接规划。
- 从同一批文件捕获的工具文本：ELF 和 COFF 使用 `llvm-objdump -h -p -T -R -d` 或 `-h -t -r`；PE 使用 `llvm-objdump -p`；Mach-O 使用 `otool -h -l -Iv`、`dyld_info -fixups -fixup_chain_details -imports -exports -function_starts` 和 `nm -m`。
- 第 40 课的读取器（`code/main.py`），或遇到未知格式会拒绝而非猜测的等效实现。

## 步骤

1. 读取头，确定格式和类型。记录魔数、type 或 filetype、机器类型，以及标志值与名称。遇到读取器不认识的内容就停止。
2. 列出导入及提供方。ELF：`DT_NEEDED` 和未定义的 `.dynsym` 条目，存在 `.gnu.version_r` 时加上版本名。PE：每个导入描述符及其 DLL、查找表、IAT、hint/name 条目。Mach-O：将链式导入表的库序号映射到 `LC_LOAD_DYLIB` 顺序，或使用 `nlist` 库序号。
3. 沿一次调用追踪到槽。记录调用字节和地址、桩或 PLT 条目字节及位移算术、槽地址、文件中的字，以及加载器写入的内容。PLT 条目须记录 `pushq` 索引和 `DT_JMPREL` 记录。链式修正须解码绑定或重定基址、`next`、序号或目标。IAT 槽须展示绑定前查找表与 IAT 相等。
4. 从目标文件规划链接：对每条重定位，依据表 4.9 的公式决定原地写入、直接调用、PLT 和 GOT 槽、仅 GOT 槽，或动态重定位。有链接后文件时，将规划的 PLT、GOT 和 `.rela.plt` 大小与实际文件比较。
5. 比较 `strip` 前后的符号表。列出删除的名称、保留的名称及加载器需要它们的原因，以及保留下来的表：导出、函数起点、展开表、节头或加载命令头。运行剥离后的程序，将输出与原程序并列记录。
6. 对剥离后文件运行所有可用查找器：链接器起点表（`LC_FUNCTION_STARTS`、`.pdata`、`.eh_frame`）、带准确字节模式或掩码的序言扫描，以及调用目标加入口点。对照副本评分：命中数、真阳性、假阳性、漏检。
7. 从目标文件构建签名：前 32 字节，把被重定位字节标为可变；第 32 字节之后至第一个可变字节之前的 CRC16；函数长度；引用名称。在已恢复起点处匹配。记录每次冲突及区分它的尾部字节或引用名称，或说明仍无法区分。
8. 每项结论都引用支持它的工具文本行。读取器与工具的每项不一致都标为未知，并给出地址。

## 必需报告

- 文件、格式、类型、标志、链接命令、工具链版本和捕获命令
- 导入及提供方、序号或版本，以及每项绑定的槽
- 调用追踪：调用点、桩或条目、槽、文件中的字、加载器动作，展示算术
- 链接规划：各决策的数量、规划大小；有链接后文件时还需实测大小
- 剥离比较：前后记录、删除名称、保留名称及原因、保留表、前后程序输出
- 查找器评分：每种方法的找到数、真阳性、假阳性、漏检和召回率
- 签名：每行 `.pat`、每个分配的名称、每次冲突及解决方式
- 未知项：读取器与工具不一致的每个地址，以及没有方法能命名函数的位置

## 必须拒绝

- 从文件读取 GOT、IAT 或 `__got` 字，不按格式解码就称其为地址。
- 为输入中已定义符号的调用报告 PLT 条目。
- 起点表存在时，将剥离文件的 `nm` 输出当作函数数量。
- 没有未剥离副本却为查找器评分。
- 未读取 `PT_GNU_RELRO` 和 `DF_BIND_NOW` 就声称部分或完整 RELRO。
- 比较 COFF `REL32` 与 ELF `PC32` 时，不计入 ELF 记录的加数。
- 签名与其他签名冲突，且未用尾部字节或引用名称区分，却据此命名函数。
- 使用重定位覆盖的字节构建签名，却不将它们标为可变。
- 引用工具在另一构建或另一机器上运行的数字。
- 将共享库剥离到低于加载器所需级别，却不记录导出表仍携带什么。

## 产出

返回以下各节：

1. 身份：格式、类型、标志、机器、工具链、命令。
2. 导入：各名称提供方、绑定槽、绑定时机（延迟、加载时或不绑定）。
3. 一次调用：路径追踪，含字节和算术。
4. 链接规划：决策、计数、规划与实测大小。
5. 剥离：前后对比、删除项、保留项及原因、保留表、程序输出。
6. 查找器：每种方法评分，列出漏检名称。
7. 签名：`.pat` 行、名称分配、冲突及解决方式。
8. 未知项：每项不一致和每个未命名起点。

以第一项未知结束。若没有未知，说明与工具文本匹配的修正或重定位数量，以及已命名函数数量。
