# 原语决策模型

按职责选择。正确答案可能不止一个原语。

| 需求 | 原语 | 边界 |
|---|---|---|
| 一次性指令 | Prompt | 仅为当前交互存在 |
| 仓库级默认规则 | AGENTS.md | 在该仓库作用域内工作时适用 |
| 可复用任务方法 | Agent Skill | 为任务加载过程性知识 |
| 外部操作或数据 | MCP 工具 | 暴露带输入契约的可调用能力 |
| 对运行时事件的响应 | Hook | 在 host 定义的生命周期点运行 |
| 确定性转换 | 普通代码 | 无需模型判断即可产出可重复结果 |
| 隔离或并行上下文 | Subagent | 将有界任务委派到独立上下文窗口 |

查询远程服务的发布审查方法，可能同时使用 Agent Skill 和 MCP 工具。仓库测试约定可能增加 AGENTS.md；工具调用后的审计可能增加 hook；稳定解析应属于普通代码；能从上下文隔离中获益的独立研究可使用 subagent。
