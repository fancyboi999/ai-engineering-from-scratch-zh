给定自己构建的 x86-64 目标文件、其 `llvm-objdump -d -r` 列表，以及接收待研究类型指针的函数，产出指令能证明的字段布局、循环能证明的步长、有 `-g` 构建时与 DWARF 布局的比较，以及指令无法提供的名称和限定符。可在 Claude、Cursor、Codex、OpenClaw、Hermes 或任何能读取 SKILL.md 的 agent 中使用本技能。

## 必需输入

- 目标文件、生成它的准确编译器和命令，以及从同一文件捕获的 `llvm-objdump -d -r` 文本。
- 第一参数指向该类型的函数名称，或将同一对象传给它们的调用点。
- 如有，同一源码的 `-g` 构建及其 `llvm-dwarfdump --debug-info` 文本。
- 对 C++ 目标文件，提供符号表及保存虚表的 `.data.rel.ro.*` 节的重定位记录。
- 第 41 课的恢复遍和读取器（`code/main.py`），或为每个字段记录证据指令的等效实现。

## 步骤

1. 将列表解析成函数，将每行重定位附到上一条指令，使调用携带被调用者名称。
2. 以 System V 实参寄存器为指针种子，对各函数执行正向跟踪。基址保存指针的每个内存操作数记为访问，记录根、偏移、宽度、种类、符号和存储标志。记录 64 位增量、作为循环的向后分支，以及每个调用处的实参值。
3. 对各循环，将经同一基址寄存器、相同宽度的访问分组。若偏移相隔 `d`，循环步长为 `k * d`，且有 `k` 个不同偏移，将它们折叠到一个偏移，并记录 `unrolled`。此步骤之前，不要相信超出步长的任何偏移。
4. 收集各类步长证据：移位和乘法的索引比例、循环步长、偏移差、调用点的元素偏移。步长是所有值的最大公约数。为每个值标明种类。
5. 构建字段。合并相同偏移、相同宽度的访问。只有从字段加载的值随后被用作基址或由 `lea` 推进时，才标记为指针。不同宽度的重叠访问记为冲突。
6. 有 `-g` 构建时，经缩写表及重定位后的 `.debug_str_offsets`、`.debug_addr` 表读取 DWARF 5。对照 `llvm-dwarfdump` 检查单元头、成员偏移和字节大小。逐字段比较，每行标记为 `match`、`no-evidence`、`size-mismatch`、`pointer-unproven`、`kind-mismatch` 或 `unexpected`。
7. 对照 System V 规则检查恢复布局：每字段位于自身大小的倍数处，整体大小为最严格对齐的倍数，规则要求填充的位置存在间隙。违反规则可能意味着紧凑结构体、位字段或错误字段。
8. 对 C++ 目标文件，从重定位读取各 `_ZTV` 符号：到顶部偏移、typeinfo，然后从 16 字节处的地址点起编号槽。读取各 `_ZTI` 的种类、名称字符串和基类。对从对象偏移 0 加载寄存器后出现的 `call *disp(%reg)`，将槽解析为 `disp / 8`，列出各类候选函数。反修饰每个 `_Z` 名称，与 `llvm-cxxfilt --no-strip-underscore` 核对。
9. 将每个名称、限定符、被指向类型及别名假设写为未知或推断。指令本身不能提供这些信息。

## 必需报告

针对类型报告：

- 目标文件名称、编译器、构建命令和列表路径
- 见证函数，以及它们共享同一类型的证据（调用点或分析者断言）
- 字段表，包含偏移、大小、种类、符号、访问数和每次访问地址
- 指针证据，附解引用指令
- 步长表，包含所有值及种类、折叠的循环、最终步长和大小
- 有 `-g` 构建时的 DWARF 比较行，以及检查过的单元头值
- 对照 System V 规则的对齐检查
- 对 C++：带槽与符号的虚表、typeinfo 种类与基类、带槽和候选的虚调用、反修饰名称
- 全部未知项：无证据成员、未证明指针、名称、限定符、被指向类型

## 必须拒绝

- 未检查循环展开，就报告超出步长的偏移。
- 将单个循环增量当作元素大小。
- 没有解引用就将八字节字段称为指针。
- 将一字节比较称为有符号或无符号 char。
- 没有调用点证据或已记录断言，就合并多个函数的访问为一个结构体。
- 在可重定位目标文件中按原始索引读取 `.debug_str`，或未应用重定位就读取 `.debug_addr`。
- 按 DWARF 5 布局解析 DWARF 4 头。
- 从符号起点而非地址点读取虚表槽。
- 将某个目标文件缺失虚表当成类没有虚表的证明。
- 将反编译器类型名复制到报告中作为证据。
- 编造成员名称。

## 产出

返回以下各节：

1. 见证：函数、根和别名证据。
2. 访问：带地址的完整访问表。
3. 布局：字段、指针证据、冲突、间隙和对齐检查。
4. 步长：每个值及种类、应用的折叠、步长和大小。
5. DWARF：单元头检查和比较行，或声明没有调试构建。
6. C++：虚表、typeinfo、虚调用和反修饰名称，或声明目标文件没有这些内容。
7. 未知项：证据无法覆盖的每个成员、种类、名称和限定符。

以第一项未知结束。若没有未知，说明与 DWARF 匹配的成员数，以及一致的步长来源数。
