给定自己编译的目标文件的 `llvm-objdump -d -r` 列表、目标文件和 C 源码，生成识别到的编译器惯用模式列表。每项给出类型、证据指令、解码后的源码形式，以及源码是否确认它。可在 Claude、Cursor、Codex、OpenClaw、Hermes 或任何能读取 SKILL.md 的 agent 中使用本技能。

## 必需输入

- C 源码，以及生成目标文件的准确编译器、目标平台、优化级别和选项。
- 目标文件，以及从该文件捕获的 `llvm-objdump -d -r` 列表。
- 第 39 课的识别器（`code/main.py`），或为每项结论报告证据地址的等效实现。
- 至少一个反编译器在同一目标文件上的输出，记录工具版本，供对照使用。

## 步骤

1. 将列表解析为函数和指令。把每行重定位附到前一条指令，从文件格式行记录架构。
2. 寻找常数除法。x86-64 上查找带 32 位立即数的 `imul`，或为 `imul` 提供输入的 `mov $imm`，然后查找移位和符号修正或加法修正。AArch64 上查找构建常数的 `mov` 和 `movk`，随后是 `smull` 或 `umull` 和移位。依据 Granlund-Montgomery 界，从乘数和总移位量还原除数；只有算法返回相同常数才接受。
3. 将已识别商乘回除数再相减的形式、`msub` 形式，或对 2 的幂使用偏置和掩码的形式识别为取模。商若同时服务于其他用途，保留除法和取模两项。
4. 按降低方式分类每个 switch：跳转表（通过地址表间接跳转，条目来自重定位或字节）、查找表（按索引加载数值，条目来自重定位地址的字节；RIP 相对字段需加 4）、线性映射（由边界比较选择的仿射运算）、比较树（以有序比较分割相等测试）、比较链（只有相等测试）或选择链。读取边界检查以确定条目数，将条目与源码 case 对照，允许编译器折叠进去的固定倍数。
5. 通过目标能够再次到达该分支的向后分支查找循环。使用 SIMD 寄存器的循环体是向量化循环：报告通道、累加器、每次迭代元素数、迭代次数掩码、最少迭代次数保护、归约和标量余数循环。同一基址的连续偏移上有 N 次加载的循环体，展开因子为 N。
6. 查找尾调用（带调用重定位的 `jmp` 或 `b`）、内联的被调用者（源码存在调用、没有调用指令、被调用者函数体形态出现在调用者中）、库替换（循环或固定复制转向 `memset`、`memcpy`）和内联展开（一对 16 字节加载与存储）。
7. 使用源码参数名，对 `cmov`、`setcc`、`csel`、`cneg` 或 `cset` 前的直线代码求值，解码无分支选择。
8. 单独报告加固形态：栈保护器（保护值加载、槽、比较、`__stack_chk_fail`）和 `endbr64`。
9. 对照源码验证每个模式：除数出现在 `/` 或 `%` 后，switch 存在且 case 匹配，循环存在，被调用者确实被调用，选择表达式存在。逐项标明是否验证通过，先列出未验证项。
10. 与反编译器输出对照：逐个模式说明工具是否折叠它、保留为算术或打印为其他形式，并引用工具文本。

## 必需报告

针对目标文件报告：

- 编译器、目标、优化级别、选项及列表工具版本
- 每个函数的全部模式，包括类型、解码后的源码形式、证据地址及验证状态
- 除法的乘数、总移位量、除数、误差，以及编译器常数是否符合算法
- switch 的降低类型、条目数、表位置、条目或目标，以及证据类型（重定位或字节）
- 循环的通道、累加器、每次迭代元素数、余数循环或展开因子
- 每个优化级别的类型矩阵，以及两个级别是否产生相同代码
- 反编译器对照，包含引用的输出及工具版本
- 源码未确认的每个模式，以及原因

## 必须拒绝

- 不看移位量，仅凭乘数命名除数。同一乘数在不同移位量下表示不同除数。
- 将查找表报告为跳转表，或将跳转表报告为死代码。
- 条目是重定位时，却从可重定位目标文件的零字节读取条目。
- 将通向共享默认块的向后分支算作循环。
- 将库尾调用称为从函数返回。
- 把 `-O0` 的硬件除法当成该编译器不存在魔数乘法的证明。
- 未引用反编译器对这个目标文件的输出，却声称它折叠某个模式。
- 报告源码不存在的模式，却未标记为未验证。

## 产出

返回以下各节：

1. 构建：编译器、目标、级别、选项、列表工具。
2. 模式：逐函数给出类型、源码形式、证据、是否已验证。
3. 除法：魔数表，含除数、乘数、移位量、误差、加法形式和算法匹配情况。
4. Switch：逐函数逐级别给出降低方式、条目及证据类型。
5. 循环：逐循环给出向量化和展开事实。
6. 反编译器：逐模式说明是否折叠，附引用文本和版本。
7. 未验证：源码未确认的每个模式。

以未验证列表结束。若为空，说明识别到的模式总数，以及常数符合算法的除法数量。
