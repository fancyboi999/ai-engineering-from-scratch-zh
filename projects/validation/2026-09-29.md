```bash
node site/build.js

node --test site/test_projects_data.js site/test_project_certificates.js site/test_project_figure_runtime.js site/test_dataset_project_figures.js site/test_budget_project_figures.js site/test_semantic_project_figures.js
```

本地核心运行使用 macOS arm64、Python 3.12.12、Node 25.6.1、Rust 1.95.0 和 Go 1.26.0。可选 Python SDK 套件在隔离环境使用 Python 3.12。各项目依赖文件固定框架版本和安装命令。项目 CI 另用 Python 3.12、Node 24、Go 1.23 和运行器的 Rust 工具链；本地通过不确立远程 CI 状态。

## 浏览器与产物检查

初次验收时，在浅色 1440x950 和深色 390x950 下检查服务中的目录、试点和文档提取页面，扩展此前两种主题、两种宽度的检查。独立打开全部 48 项目页，演练动态 provider 加载。全部 197 机制图挂载，接受输入变化并更新可见计算，没有初始错误。更早的界面检查覆盖项目筛选、阶段导航和浏览器历史、保存完成进度、录制播放／停止及证书导入。

八个新应用输出在 1120 和 390 像素检查。文档审阅检查选中 Unicode 字符后的源片段，下载实际批准文件，经 CLI 应用，再打开批准页面，选择未丢失。学习教练在浏览器记录错误及正确答案；下载的尝试事件经 CLI 重放成预期日程。

证书导入拒绝参考解证据，接受完整学习者模式 QA 报告。QA 工作区故意复制参考实现，仅为演练界面，不宣称学习者成就。证书仍是本地自报社区记录，无法确立身份，也无法阻止复制代码或修改 JSON。

浏览器 agent adapter 用真实 Chromium 访问本地 fixture 并捕获结果。Rust shell 经真实 stdin/stdout 和 PTY 演练。试点报告在 Chromium 打开，检查引用并展开追踪。终端 GIF 渲染捕获的命令输出；应用输出 GIF 使用真实浏览器帧捕获。四个框架 GIF 记录当前可选评分器，区分核心和额外 SDK 测试数。

## 评审跟进检查

修正后，投稿卡片、预算阶段 4 和语义搜索阶段 3 在 1280、390 像素和两种主题下，通过 12 项路由／宽度／主题检查。服务中的预算回执使用 `events[].status`。语义图保留可编辑示例中的字面复数匹配，解释不同文件 fixture，并将 `constructor` 和 `__proto__` 正确作为普通搜索词排序。检查未发现文档溢出或控制台错误。

生成的会议 HTML 经真实下载处理器保留批准和拒绝选择。畸形与有效 PR 候选混合输入产生一致 HTML 和 JSON。实际 Browser Agent CLI 用四步完成本地 Chromium fixture，生成有效截图；独立损坏截图测试保留失败回执。fixture 成功不是通用浏览器准确性声明。

回归测试覆盖 provider HTTPS 和重定向边界、真实传输重试后的网关请求重放、有界 HTTP 连接关闭、分段 UTF-8 请求体、可选云日志窗口、原子补丁清理、根层 glob 匹配及原生进程终端回执。会遗漏既有阶段测试的单文件运行器覆盖被移除。全量评分还发现并行桌面 fixture 目录冲突；原子序列修复后，30 次重复集成运行全部 150 测试通过，再执行最终全量门禁。

日历保留文档化的明确端点子集，包括全天事件排他结束。数字提取保留有限 Python 浮点语法，包含接受与拒绝案例。这两条评审建议需要的是更清晰契约，不是更宽解析器。可选 SDK 路线的集成代码未变，本次跟进没有重跑。

## 集成与回归检查

持久作业和评估农场运行真实子进程，在文档化边界崩溃，恢复持久工作并拒绝过期完成。Harness 和网关二进制发出真实 loopback HTTP 请求，带调用预算、不同凭据、截止时间和有界响应体。Mastra 在一个进程暂停工作流，在另一个进程恢复同一已存储运行。官方 MCP 客户端通过 stdio 和 HTTP 演练教学服务器。

跨项目检查包括：审计后的数据分区用于评估、PR 发现用于评审面板、已安装技能包用于原生 Rust 校验器、研究报告用于评判器。独立应用评审复现并修复另三个缺陷：大 CSV 标识符合并、批准提取选择导出时消失、复盘文本丢失审阅元数据。回归测试和原始复现均通过。

## 限制

没有执行原生 macOS 桌面控制。fixture 后端成功不验证辅助功能权限或原生交互。可选框架套件导入并执行真实 SDK，使用确定性本地模型；没有实时模型 provider、Bedrock 或其他云调用。语音测试用受控响应验证真实 WAV／multipart 传输；离线转录明确提供，不衡量识别准确率。视觉搜索使用给定文本矩形，不宣称 OCR。

沙箱阶段教授策略规划；未演练可选 Docker 探测。队列和农场恢复覆盖本地文件系统上的协作进程，不覆盖分布式存储或外部效果恰好一次语义。评估集是公开教学 fixture，其分数不确立未见数据表现。源哈希绑定内容，不绑定评审者身份。本地草稿不发送邮件、发布 issue 或更改账户日历。
