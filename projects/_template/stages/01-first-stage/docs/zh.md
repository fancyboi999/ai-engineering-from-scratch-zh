## 要构建什么

在 `your_package/first.py` 实现 `first_function(argument: str) -> str`。它返回规范化标识符，或抛出错误，区分输入类型不对和语法不对。

## 为什么重要

worker 如果把 `Ship-Report` 与 `ship-report` 当作不同任务，可能重复交付。解析器在任务进入持久存储前确立唯一表示。

## 核心概念

先去掉首尾空白，将标签转成小写，再校验整个结果。例如 `  Ship-Report2  ` 变成 `ship-report2`。内部空白仍然无效。不要删除坏字符直到字符串碰巧通过：`ship/report` 与 `ship-report` 可能指不同任务。

标记项目就绪前，添加原创且已注册的 `figure` 机制图。展示输入、规范化、长度检查、语法检查，以及接受或拒绝的终止状态。

## 你的任务

```python
def first_function(argument: str) -> str: ...
```

非字符串输入用 `TypeError` 拒绝。规范化标签长度必须为 1 到 32 个字符，以 ASCII 字母开头；其余只能含小写 ASCII 字母、数字，或分隔非空片段的单个连字符。无效字符串抛出 `ValueError`。函数不产生文件系统或网络影响。
