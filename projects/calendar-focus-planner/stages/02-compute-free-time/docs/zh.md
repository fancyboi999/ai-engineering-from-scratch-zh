# 先合并重叠，再寻找空档

**类型：** Build
**语言：** TypeScript
**阶段：** 第 2 阶段，共 4 阶段
**预计时间：** 约 2 小时，需先完成链接中的前置内容
**前置要求：** 前一阶段，以及[开发环境](../../../../../phases/00-setup-and-tooling/01-dev-environment/docs/zh.md)、[数据管理](../../../../../phases/00-setup-and-tooling/09-data-management/docs/zh.md)。

## 构建内容

本阶段推进日历专注计划器：找到日历中的真实空闲时间，安排优先任务，并解释哪些任务放不下。

公开契约为 `availableSlots(events, window, bufferMinutes=0)`。随附 CLI 和样本文件位于你的工作区；在 `main.ts` 中实现领域函数。保留签名，使其他应用也能调用同一边界。

## 推演机制

两场重叠会议占用的时间不等于它们的时长之和。按所选缓冲扩展各事件，裁剪到工作窗口，按开始时间排序，并合并重叠或相邻区间。该并集的补集就是真实空档。

游标从工作窗口起点开始。每个忙碌区间之前，只在区间开始晚于游标时输出空档。将游标移到忙碌区间末尾。最后一个事件之后输出剩余尾段。这种方法易于解释，处理嵌套会议时不会重复计数。

| 带 10 分钟缓冲的输入 | 合并后的占用区间 |
|---|---|
| 09:20–10:25 和 09:50–11:10 | 09:20–11:10 |
| 12:50–14:40 | 12:50–14:40 |
| 工作窗口 | 09:00–17:00 |

## 逐级提示

1. 先裁剪，再丢弃窗口外的区间。
2. 将每个开始值与最后一个已合并区间的结束值比较。
3. 返回新对象，保持调用者的事件不变。

## 扩展

改变缓冲，找到 75 分钟任务恰好放不下的临界点。

范围：解析器支持显式 UTC 事件和全天日期。重复规则和命名时区必须先由日历导出器展开，遇到它们会拒绝。CLI 规划 UTC 09:00–17:00 的一天。它只创建本地建议，从不修改账号日历。

主要参考：[iCalendar RFC 5545](https://www.rfc-editor.org/rfc/rfc5545)。实现和练习数据均为原创教学示例。
