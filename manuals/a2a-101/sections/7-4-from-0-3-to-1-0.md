# 从 0.3 到 1.0

> 1.0 重命名所有操作、改变所有枚举值、平铺卡片和 part，并拒绝缺少 `A2A-Version` 的请求，0.3 客户端需要兼容层。

套件错误场景发送两条 0.3 客户端如今会发送的请求：一条省略 `A2A-Version`，得到 `VersionNotSupportedError`；另一条调用 `message/send`，得到 `MethodNotFoundError`。读完本节后，你可以将 0.3 请求映射到 1.0 形式，并开启参考 SDK 的 0.3 层。

```listing
title: 1.0 端点上的 0.3 方法名
source: capture/out/11-errors.http
lang: http
note: 错误场景的第三条记录。params 中的消息已删节。
---
POST /a2a/jsonrpc HTTP/1.1
Host: localhost:41241
Content-Type: application/json
A2A-Version: 1.0

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "message/send",
  …
}

HTTP/1.1 200 OK
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 3,
  "error": {
    "code": -32601,
    "message": "Method not found"
  }
}
```

## 变更前后 {#s-from-0-3-to-1-0-before-and-after}

项目迁移指南列出变更，因为引入重大破坏性变更时 `MUST` 通过辅助文档提供迁移指导。下表保留影响代码的变更。 {{docs whats-new-v1}} {{spec §1.4}}

| 范围 | 0.3 | 1.0 |
|---|---|---|
| 方法名 | `message/send`、`tasks/get`、`tasks/resubscribe` | `SendMessage`、`GetTask`、`SubscribeToTask`，每种绑定使用同一 PascalCase 名  {{spec §9.1}} |
| 推送配置方法 | `tasks/pushNotificationConfig/set`，以及 `/get`、`/list`、`/delete` | `CreateTaskPushNotificationConfig`，以及 `Get`、`List`（复数 `Configs`）、`Delete` |
| 扩展卡片 | `agent/getAuthenticatedExtendedCard`，REST `GET /v1/card` | `GetExtendedAgentCard`，REST `GET /extendedAgentCard`，无 `/v1` 前缀 |
| 任务状态 | `"working"`、`"input-required"` | `TASK_STATE_WORKING`、`TASK_STATE_INPUT_REQUIRED`  {{proto TaskState}} |
| 角色 | `"user"`、`"agent"` | `ROLE_USER`、`ROLE_AGENT`  {{proto Role}} |
| part 结构 | `TextPart`、`FilePart`、`DataPart`，各带 `kind` | 一个 `Part`，由 `text`、`raw`、`url`、`data` 成员指定类型  {{proto Part}} |
| 文件字段 | `file.mimeType`、`file.name`、`file.fileWithUri` | `mediaType`、`filename`、`url`，平铺在 part 上 |
| 流帧 | `"kind": "status-update"` | `statusUpdate` 或 `artifactUpdate` 成员  {{proto StreamResponse}} |
| 流的结束 | 最后状态更新带 `final: true` | 绑定关闭流 |
| 卡片端点 | `url`、`protocolVersion`、`preferredTransport`、`additionalInterfaces` | `supportedInterfaces[]`，各含 `url`、`protocolBinding`、`protocolVersion`  {{proto AgentInterface}} |
| 扩展卡片标志 | `supportsAuthenticatedExtendedCard` | `capabilities.extendedAgentCard` |
| 卡片安全 | `security` | `securityRequirements`，各含 `schemes` 映射  {{proto AgentCard}} |
| 错误 | RFC 9457 problem details | 带 `ErrorInfo` 的 `google.rpc.Status`，新增 `-32008`、`-32009`  {{spec §5.4}} |
| 版本头 | 无 | 每次请求带 `A2A-Version: 1.0`  {{spec §3.6.1}} |

source: research/sources/docs.md

note: 迁移指南的 0.3 卡片示例。前四个字段变为 supportedInterfaces，第五个变为 capabilities.extendedAgentCard。

{
  "protocolVersion": "0.3",
  "url": "https://agent.example.com/a2a",

指南漏掉一项：0.3 的 `blocking` 默认 false，发送立即返回。替代它的 `returnImmediately` 也默认 false，现在发送会等待。[SendMessage](#s-send-message) 展示两种模式。 {{proto SendMessageConfiguration}} {{spec §3.2.2}}

## 缺失的头 {#s-from-0-3-to-1-0-the-missing-header}

agent `MUST` 将空值解释为 0.3。仅 1.0 的接口必须返回 `VersionNotSupportedError`，套件正是如此。 {{spec §3.6.2}} {{spec §5.4}}

SDK 不同。JS、Java 在所有绑定将缺失头视为 0.3 并拒绝，Python 在 JSON-RPC 和 REST 如此，Rust 只在 JSON-RPC 如此。Go 从不读头，.NET 接受缺失。[版本头](#s-version-and-extension-headers)给出完整表。 {{sdk-js src/server/version.ts at v1.3.0}} {{sdk-java server-common/src/main/java/org/a2aproject/sdk/server/version/A2AVersionValidator.java at v1.4.0.Final}} {{sdk src/a2a/utils/version_validator.py}} {{sdk-rust a2a-server/src/jsonrpc.rs at a2a-server-lf-v0.5.1}} {{sdk-go a2a/svcparams.go at v2.6.0}} {{sdk-dotnet src/A2A.AspNetCore/A2AJsonRpcProcessor.cs at v1.0.0-preview2}}

## 各 SDK 的 0.3 层 {#s-from-0-3-to-1-0-the-0-3-layer-in-each-sdk}

服务器可在过渡期同时接受旧版和当前请求消息形式。 {{spec §A.2}}

- **a2a-python 1.2.2。** 向 `create_jsonrpc_routes` 和 `create_rest_routes` 传 `enable_v0_3_compat=True`，在卡片加 `protocolVersion` 为 `0.3` 的 `AgentInterface`。dispatcher 按方法名路由，`message/send` 在版本检查前到达 `JSONRPC03Adapter`。gRPC 在旧包 `a2a.v1` 添加 `CompatGrpcHandler`。客户端无需开关，`ClientFactory` 为低于 `1.0` 的接口选择兼容传输。 {{sdk src/a2a/server/routes/jsonrpc_routes.py}} {{sdk src/a2a/server/routes/rest_routes.py}} {{sdk src/a2a/server/routes/jsonrpc_dispatcher.py}} {{sdk src/a2a/compat/v0_3/grpc_handler.py}} {{sdk src/a2a/client/client_factory.py}}
- **a2a-js 1.3.0。** 每个 handler 设置 `legacyCompat: { enabled: true }`，按 `A2A-Version` 路由，缺失头视为 `0.3`。 {{sdk-js src/server/express/json_rpc_handler.ts at v1.3.0}}
- **a2a-go 2.6.0。** 在独立 URL 挂载来自 `a2acompat/a2av0` 的第二个 handler，声明第二个接口。按 URL 路由，不按头。 {{sdk-go a2acompat/a2av0/jsonrpc_server.go at v2.6.0}}
- **a2a-java 1.4.0.Final。** 添加 `multiversion-jsonrpc` 或 `multiversion-rest` 参考模块，其 `VersionRouter` 将 `0.3` 或缺失头送到 0.3 handler。 {{sdk-java docs/content/dev/compatibility.md at v1.4.0.Final}}
- **a2a-dotnet 1.0.0-preview2。** 用 `MapA2AWithV03Compat` 代替 `MapA2A`，按 `A2A-Version` 路由。 {{sdk-dotnet src/A2A.V0_3Compat/V03ServerCompatEndpointExtensions.cs at v1.0.0-preview2}}
- **a2a-rs 0.5.1。** 无。 {{sdk-rust a2a-client/src/factory.rs at a2a-server-lf-v0.5.1}}

## 迁移指南的错误 {#s-from-0-3-to-1-0-where-the-migration-guide-is-wrong}

proto 具有规范性，指南指定 proto 没有的字段或值时，以 proto 为准。 {{spec §1.4}}

- 指南称流成员为 `taskStatusUpdate` 和 `taskArtifactUpdate`，proto 是 `statusUpdate` 和 `artifactUpdate`（[冲突 D9](#s-ref-sources)）。[PR #2056](https://github.com/a2aproject/A2A/pull/2056)在 v1.0.1 后的 main 修复，尚未发布。
- 指南添加 proto 没有的 `Task.createdAt`、`Task.lastModified`、`configId` 和产物 `index`（[冲突 D10](#s-ref-sources)）。同一 PR 删除了除 `index` 之外的这些字段。
- 附录 A.2.2 将旧标志称为 `supportsExtendedAgentCard`，指南与 SDK 用 `supportsAuthenticatedExtendedCard`（[冲突 D40](#s-ref-sources)），main 未修复。
- 指南将扩展放在 `agentCard.extensions`，proto 放在 `capabilities.extensions`，见[扩展](#s-extensions)。 {{proto AgentCapabilities}}

## v1.0.1 之后 {#s-from-0-3-to-1-0-after-v1-0-1}

尚无比 `v1.0.1` 更新的标签。自该标签以来 main 只有一项 proto 变更：gRPC `url` 注释改为 `hostname:port`（[PR #1997](https://github.com/a2aproject/A2A/pull/1997)），解决 D34。这是待发布 1.0.2 的唯一条目（[PR #2072](https://github.com/a2aproject/A2A/pull/2072)）。

main 文档提交解决 D8、D9、D12、D32，及 D4、D5、D6、D10、D23 的部分问题（[冲突登记](#s-ref-sources)）。main 还添加任务内授权范围的 §7.6.4（[PR #2081](https://github.com/a2aproject/A2A/pull/2081)），[安全方案](#s-security-schemes-and-in-task-authorization)引用它。

`dev-1.1` 分支改变任务记录：`Task.generation` 计数每次状态变化，`GetTaskRequest.currentGeneration` 让客户端等待下次变化。`SendMessageConfiguration.ifGenerationMatch` 使发送有条件，旧值得到 `TaskGenerationMismatchError`、`-32010`（[PR #1810](https://github.com/a2aproject/A2A/pull/1810)）。`Task.history` 被弃用，改为消息和状态的 `timeline`（[PR #2129](https://github.com/a2aproject/A2A/pull/2129)）。这些都未发布，1.1 日期也未公布。

```takeaways
- 每次请求发送 `A2A-Version: 1.0`，0.3 客户端依赖 `blocking: false` 的地方设置 `returnImmediately`。
- 旧客户端仍存在时，开启 SDK 0.3 层并在卡片添加 `0.3` 接口。
- 迁移指南指定 proto 没有的字段时，以 proto 为准。
- 标签发布之前，将 `generation` 和 `timeline` 视为未发布功能。
```
