# 图表索引

> 按顺序列出本手册全部图表，以及每幅图注作出的核心声明。

每行链接到对应图表，声明就是图注开头的粗体句。图中每个数值都来自 `capture/out/`，图注注明具体文件。颜色遵循前言中的调色板：

- 蓝色表示 rea、CLI、MCP 服务与领域层
- 紫色表示 Ghidra 提供器
- 绿色表示样例文件与其字节
- 梅紫色表示 agent 及模型调用
- 橄榄色表示脚本与托管代码
- 靛蓝色表示 MCP 消息与会话
- 琥珀色表示生命周期状态，如声明状态
- 青色表示持久记录，如证据包
- 玫红色表示失败或被拒绝的声明
- 灰色表示宿主机、编译器与读者
