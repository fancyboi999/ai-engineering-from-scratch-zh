## 提示 1

回复是 JSON 文本，其中每个 `arguments` 字段也是 JSON 文本。先对正文调用 `json.loads`，再对每个 `arguments` 字符串调用一次。

## 提示 2

编写一个递归函数，接收 schema、值、路径和错误列表。函数向列表追加错误，不返回值。`validate_args` 从空路径开始，并将空路径显示为 `/`。

## 提示 3

判断值的 JSON 类型时，先检查 `bool`，再检查 `int`。在 Python 中，`isinstance(True, int)` 为真。

## 提示 4

出现类型或枚举错误后立即返回。对于对象，先完成 `required` 循环，再遍历值的键。路径段中先转义 `~`，再转义 `/`，否则 `~1` 中的 `~` 会再次变化。
