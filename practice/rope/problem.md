旋转位置编码（RoPE）会将 token 的位置信息写入 query 和 key 向量。它按位置对应的角度旋转每对坐标，因此 query 和 key 的注意力分数只取决于它们的位置差。大多数开放语言模型都使用 RoPE。

## 任务

编写两个函数。

1. `rope_frequencies(d, base=10000.0)` 返回每对坐标的频率。
2. `apply_rope(x, positions, base=10000.0)` 返回旋转后的 `x` 副本。

坐标对 `i` 的频率为 $\theta_i = \text{base}^{-2i/d}$，其中 $i = 0, 1, \dots, \lfloor d/2 \rfloor - 1$。

坐标对 `i` 包含相邻的两个坐标 `2i` 和 `2i + 1`。对于位置 $p$ 处的 token，令 $a = x_{2i}$、$b = x_{2i+1}$、$\phi = p \, \theta_i$。输出坐标对为：

$$a' = a \cos\phi - b \sin\phi, \qquad b' = a \sin\phi + b \cos\phi$$

`d` 为奇数时，最后一个坐标没有配对项。将它原样复制到输出。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `d` | int | | 最后一个轴的长度 |
| `base` | float | | 频率底数 |
| `x` | float 数组 | `(..., T, d)` | `T` 个 token 的向量，可带零个或多个前置 batch 轴 |
| `positions` | int 或 float 数组 | `(T,)` | 每个 token 的位置 |

- `rope_frequencies` 返回形状为 `(d // 2,)` 的浮点数组。
- `apply_rope` 返回与 `x` 同形状的新浮点数组。

## 约束

- `1 <= T <= 64`，且 `2 <= d <= 128`。
- 位置范围为 0 到 1000000。
- positions 对应 `x` 的倒数第二个轴。每个前置轴使用相同的旋转。
- 使用 `(0, 1), (2, 3), ...` 这样的配对。不要将坐标 `i` 与坐标 `i + d/2` 配对。
- 不要修改输入数组。
- 仅使用 numpy。

## 示例

```python
rope_frequencies(8)
```

```text
[1.    0.1   0.01  0.001]
```

```python
x = np.array([[1.0, 0.0, 1.0, 0.0], [1.0, 0.0, 1.0, 0.0], [1.0, 0.0, 1.0, 0.0]])
apply_rope(x, np.arange(3))
```

```text
[[ 1.          0.          1.          0.        ]
 [ 0.54030231  0.84147098  0.99995     0.00999983]
 [-0.41614684  0.90929743  0.99980001  0.01999867]]
```

```python
q = np.array([[1.0, 2.0, 3.0, 4.0]])
k = np.array([[0.5, -1.0, 2.0, 1.0]])
apply_rope(q, [2])[0] @ apply_rope(k, [5])[0]
apply_rope(q, [10])[0] @ apply_rope(k, [13])[0]
```

```text
11.912706599522757
11.912706599522759
```
