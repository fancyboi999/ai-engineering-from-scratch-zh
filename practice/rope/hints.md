## 提示 1

先计算频率。`np.arange(d // 2)` 会得到配对索引 `i`。指数为 `2 * i / d`，不是 `i / d`。

## 提示 2

构造形状为 `(T, d // 2)` 的角度表。每项等于位置乘以频率。使用 `positions[:, None]`，并给频率数组增加一个首轴。

## 提示 3

切片 `0:2 * (d // 2):2` 选出每对的第一个元素，`1:2 * (d // 2):2` 选出第二个元素。`d` 为奇数时，这些切片也有效。

## 提示 4

先复制 `x`。从 `x` 中读取 `a`、`b`，再把旋转后的两个部分写入副本。`d` 为奇数时，副本会保留最后一个坐标。
