幂迭代只需反复进行矩阵乘法，就能找到矩阵的主特征向量。每次将向量乘以矩阵，向量都会逐渐转向绝对值最大的特征值对应的特征向量。SVD 课程会用它处理 $A^T A$ 并求出奇异值，PCA 则用它寻找第一主成分。

## 任务

编写两个函数。

1. `fix_sign(v)` 返回符号固定的 `v` 副本。找到绝对值最大的元素索引；若并列，选择最靠前的索引。该元素为负时返回 `-v`，否则返回 `v` 的副本。
2. `power_iteration(M, v0, num_iters=200, tol=1e-10)` 返回 `(eigenvalue, vector, iters)`，对应 M 中绝对值最大的特征值及其特征向量。

在 `power_iteration` 中执行以下步骤。

1. 设置 $v = v_0 / \|v_0\|$。
2. 对 $k = 1, 2, \ldots,$ `num_iters` 重复以下步骤：
    - 计算 $w = M v$。
    - 若 $\|w\| <$ `tol`，停止并返回 `(0.0, fix_sign(v), k)`。
    - 设置 $v_{new} = w / \|w\|$。
    - 若 $|v_{new} \cdot v| > 1 -$ `tol`，设置 $v = v_{new}$ 并停止。
    - 否则设置 $v = v_{new}$。
3. `iters` 是停止时的 $k$。若迭代未提前停止，则 `iters` 等于 `num_iters`。
4. 特征值使用最终 $v$ 的 Rayleigh 商 $v^T M v$ 计算。
5. 返回 `(eigenvalue, fix_sign(v), iters)`。

检查会对点积取绝对值。若主特征值为负，$v$ 的符号会在每一步翻转，但算法仍应检测到收敛并停止。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `v` | float 数组 | `(n,)` | 传给 `fix_sign` 的向量 |
| `M` | float 数组 | `(n, n)` | 对称矩阵 |
| `v0` | float 数组 | `(n,)` | 非零初始向量 |
| `num_iters` | int | 标量 | 最大迭代次数 |
| `tol` | float | 标量 | 两个停止条件使用的容差 |

- `fix_sign` 返回形状为 `(n,)` 的浮点数组。
- `power_iteration` 返回元组：一个 Python `float`、一个形状为 `(n,)` 的浮点向量，以及一个整数。

## 约束

- `1 <= n <= 50`，且 `1 <= num_iters <= 5000`。
- `M` 是对称矩阵。按绝对值排序后，主特征值与下一个特征值之间存在间隔。
- 不要修改输入数组。
- 仅使用 numpy。不要调用 `np.linalg.eig` 或 `np.linalg.eigh`。

## 示例

```python
fix_sign(np.array([0.1, -0.9, 0.3]))
```

```text
[-0.1  0.9 -0.3]
```

```python
M = np.array([[4.0, 1.0, 0.0], [1.0, 3.0, 1.0], [0.0, 1.0, 2.0]])
power_iteration(M, np.array([0.0, 0.0, -1.0]))
```

```text
(4.732050806909286, array([0.78866387, 0.57736154, 0.21133613]), 26)
```

```python
power_iteration(M, np.array([1.0, 1.0, 1.0]), num_iters=3)
```

```text
(4.71702331523475, array([0.73272722, 0.62549884, 0.26807093]), 3)
```

第二个示例的初始向量为负。符号规则会让结果中绝对值最大的元素为正。
