Softmax 回归是面向两个以上类别的逻辑回归。它为每个类别计算线性分数，再用 softmax 将分数转成概率。本题用梯度下降在四个高斯点簇上训练模型。检查器会在代码从未见过的新点上评估准确率和对数损失。

## 任务

编写两个函数。

1. `train(X, y, rng)` 训练并返回模型。
2. `predict_proba(model, X)` 返回 `X` 每一行属于各类别的概率。

数据来自 `support.py` 中的 `make_blobs(n, rng)`。每个点属于 4 个类别之一。类别 $k$ 的点等于 `CENTERS[k]` 加上标准差为 0.9 的高斯噪声。`weights` 参数设置类别频率，默认各类别频率相同。

模型包含形状为 $(2, 4)$ 的权重矩阵 $W$ 和形状为 $(4,)$ 的偏置向量 $b$。概率为 $P = \mathrm{softmax}(Z W + b)$，其中 $Z$ 保存输入特征。用梯度下降最小化平均交叉熵 $-\frac{1}{N} \sum_i \log P_{i, y_i}$。两个特征的均值约为 4 和 3。用训练集统计量将其缩放为均值 0、标准差 1，并将这些统计量保存在模型中。

训练时，每次更新都要调用一次 `practice_check` 中的 `report(step, loss)`。第一步为 0。页面用这些值实时绘制损失曲线，检查器会统计调用次数。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `X` | 浮点数组 | `(N, 2)` | 训练点 |
| `y` | 整数数组 | `(N,)` | 每个点的类别，范围为 0 到 3 |
| `rng` | `np.random.Generator` | | 如需随机数，只能从此获取 |
| `model` | 任意 | | `train` 返回的值 |

- `train` 返回模型。模型可以是任意 Python 值，例如由数组组成的字典。
- 对形状为 `(M, 2)` 的输入，`predict_proba` 返回形状为 `(M, 4)` 的浮点数组。每行之和为 1。

## 约束

- 预算：最多更新 500 步，即最多调用 `report` 500 次。
- 目标：在 4000 个点组成的留出集上，准确率至少为 0.95，对数损失不超过 0.11。生成该集合的种子不在此页面公开。检查器将概率最大的类别作为预测。
- 当某一类别占 85% 的点时，也必须达到这些目标。
- 对远离数据的点，例如 `(1000, 1000)`，`predict_proba` 也必须给出有限的概率。
- 相同种子必须得到相同模型。不得修改 `X` 或 `y`。
- 只用 NumPy。一次完整提交限时 15 秒。

## 示例

```python
X, y = make_blobs(400, np.random.default_rng(0))
model = train(X, y, np.random.default_rng(1))
predict_proba(model, np.array([[1.0, 1.0], [4.0, 3.0]]))
```

```text
[[0.9994 0.0001 0.0005 0.    ]
 [0.0293 0.3585 0.5689 0.0432]]
```

输出保留 4 位小数。第一个点是类别 0 的中心。第二个点在点簇之间，因此没有任何类别的概率很高。参考解从零权重开始，因此首次报告的损失为 $\log 4 = 1.3863$。500 步后，训练对数损失为 0.0609，训练准确率为 0.9875。
