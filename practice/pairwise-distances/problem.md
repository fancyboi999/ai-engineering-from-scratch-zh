最近邻搜索、k-means 和核方法都需要计算两组点之间的两两距离。Python 中用双重循环遍历所有点对很慢。一次矩阵乘法可以同时计算所有交叉项。余弦相似度也会返回同类矩阵，用于衡量向量夹角。

## 任务

编写三个函数。

1. `pairwise_sq_distances(A, B)` 返回欧氏距离平方矩阵。第 $(i, j)$ 项是 $\|a_i - b_j\|^2$。
2. `pairwise_distances(A, B)` 返回欧氏距离矩阵 $\|a_i - b_j\|$。
3. `cosine_similarity_matrix(A, B)` 返回余弦相似度矩阵。第 $(i, j)$ 项为 $a_i \cdot b_j / (\|a_i\| \|b_j\|)$。

利用展开式 $\|a - b\|^2 = \|a\|^2 + \|b\|^2 - 2 a \cdot b$。用一次矩阵乘法计算所有点积，不要逐点对循环。

两个点相同或非常接近时，浮点舍入可能让展开结果略小于 0。将距离平方截断到不小于 0，再开平方。

零向量规则：若 $a_i$ 或 $b_j$ 是零向量，余弦矩阵的第 $(i, j)$ 项为 `0.0`。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `A` | float 数组 | `(N, D)` | `N` 个点，每行一个 |
| `B` | float 数组 | `(M, D)` | `M` 个点，维度均为 `D` |

- `pairwise_sq_distances` 返回形状为 `(N, M)` 的浮点数组，所有值都大于或等于 0。
- `pairwise_distances` 返回形状为 `(N, M)` 的浮点数组。
- `cosine_similarity_matrix` 返回形状为 `(N, M)` 的浮点数组，所有值都在 -1 到 1 之间。

## 约束

- `1 <= N, M <= 500`，且 `1 <= D <= 512`。
- 行向量可以为零。输入值最大可达 `1e5`。
- 不要修改输入数组。
- 仅使用 numpy。

## 示例

```python
A = np.array([[0.0, 0.0], [3.0, 4.0]])
B = np.array([[3.0, 0.0], [0.0, 4.0], [3.0, 4.0]])
pairwise_sq_distances(A, B)
```

```text
[[ 9. 16. 25.]
 [16.  9.  0.]]
```

```python
pairwise_distances(A, B)
```

```text
[[3. 4. 5.]
 [4. 3. 0.]]
```

```python
cosine_similarity_matrix(A, B)
```

```text
[[0.  0.  0. ]
 [0.6 0.8 1. ]]
```

`A` 的第一行是零向量，因此该行的所有相似度都为 0。
