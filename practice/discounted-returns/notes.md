## 为什么要从后向前计算

回报满足 $G_t = r_t + \gamma G_{t+1}$。从末尾向前遍历，只需 $O(T)$ 时间就能得到全部回报。若每一步都从头求和，则需要 $O(T^2)$ 时间。

## 为什么先重置再累加

done 标记所在的步骤会在得到奖励后结束 episode。该步奖励属于当前 episode 的回报；之后的奖励属于下一条 episode。因此要先把累计值重置为 0，再加入当前步奖励。若存储回报后才重置，就会切错 episode。

## 批次截断

本题把批次末尾视为 episode 结束。实际 rollout 常在 episode 中途停止，此时回报会漏掉未来奖励。Actor Critic 和 PPO 课程会用 critic 的 bootstrap value 补足这部分。广义优势估计练习也会用到它。

## 为什么要归一化

回报数值可能很大，而且训练中尺度会变化。REINFORCE 课程会在梯度更新前，将整个批次的回报缩放到均值为 0、标准差为 1，以稳定更新步长。Actor Critic 和 PPO 课程也使用同一个 `normalize` 函数，只是作用对象变成优势值。
