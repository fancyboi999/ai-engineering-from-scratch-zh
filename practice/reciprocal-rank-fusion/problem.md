倒数排名融合（RRF）会把不同检索器的排序列表合成一个列表。它只使用文档排名，不使用原始分数。BM25 分数和余弦相似度的尺度不同，但排名可以比较。混合搜索会用 RRF 合并关键词和向量检索结果。

## 任务

编写两个函数。

1. `rrf_scores(rankings, k=60, weights=None)` 返回每份文档的融合分数。
2. `fuse(rankings, k=60, weights=None)` 按融合分数排序后返回文档。

每个排名列表包含文档 ID，并按最佳结果在前排列。列表首个文档的 rank 为 1。文档 $d$ 的融合分数为：

$$\mathrm{RRF}(d) = \sum_{i} \frac{w_i}{k + \mathrm{rank}_i(d)}$$

求和遍历所有包含 $d$ 的列表。不包含 $d$ 的列表不增加分数。`weights` 为 `None` 时，所有 $w_i$ 都为 1。

若 `weights` 不为 `None`，且其长度与列表数量不同，则抛出 `ValueError`。

并列规则：`fuse` 按分数从高到低排序。分数相同时，doc id 较小者靠前。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `rankings` | 由 int 列表组成的列表 | `L` 个列表 | 每个列表包含不重复的文档 ID，最佳结果在前 |
| `k` | int | 标量 | RRF 常数，默认 `60` |
| `weights` | float 列表或 `None` | `L` 个值 | 每个列表的权重 |

- `rrf_scores` 返回 `dict`，将所有列表中出现的文档 ID 映射为 `float` 融合分数。
- `fuse` 返回 `(doc_id, score)` 元组列表，最佳结果在前，且包含 `rrf_scores` 中的所有文档。

## 约束

- `0 <= L <= 10`，每个列表最多包含 1000 个 ID。列表可以为空。
- 文档 ID 是非负整数。同一 ID 在一个列表中最多出现一次。
- `k >= 1`，且每个权重都为正数。
- 不要修改输入列表。
- 仅使用 Python 和 numpy。

## 示例

```python
bm25 = [3, 1, 4]
dense = [1, 5, 3]
fuse([bm25, dense])
```

```text
[(1, 0.03252247488101534), (3, 0.032266458495966696), (5, 0.016129032258064516), (4, 0.015873015873015872)]
```

文档 1 的排名为 2 和 1，因此分数为 $1/62 + 1/61$。文档 3 的排名为 1 和 3，因此分数为 $1/61 + 1/63$。文档 1 排在前面。

```python
fuse([bm25, dense], weights=[2.0, 1.0])
```

```text
[(3, 0.04865990111891751), (1, 0.048651507139079855), (4, 0.031746031746031744), (5, 0.016129032258064516)]
```
