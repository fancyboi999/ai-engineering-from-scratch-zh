带一个 tanh 隐藏层的网络可以把直线弯成平滑曲线。本题要训练 1-16-1 tanh 网络，根据带噪样本拟合 $\sin(x)$。检查会在你的代码从未见过的新点上，将训练结果与真实曲线比较。

## 任务

编写两个函数。

1. `train(x, y, rng)` 训练网络并返回训练后的模型。
2. `predict(model, x)` 返回网络对 `x` 中每个值的预测。

数据由 `support.py` 中的 `make_sine(n, rng)` 生成。每个 $x$ 均匀分布在 $-\pi$ 到 $\pi$ 之间，且 $y = \sin(x) + \varepsilon$，其中高斯噪声的标准差为 0.1。

网络有 1 个输入、16 个 tanh 隐藏单元和 1 个线性输出：$\hat y = \tanh(x W_1 + b_1) W_2 + b_2$。使用全批次梯度下降最小化均方误差 $\frac{1}{N} \sum_i (\hat y_i - y_i)^2$。Adam 较容易达到目标。

训练过程中，每次参数更新都要调用一次 `practice_check` 中的 `report(step, loss)`。步数从 0 开始。页面会将这些值绘制为实时损失曲线，检查也会统计调用次数。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `x` | float 数组 | `(N,)` | 训练输入，范围为 $-\pi$ 到 $\pi$ |
| `y` | float 数组 | `(N,)` | 带噪目标值 |
| `rng` | `np.random.Generator` | | 唯一的随机数来源 |
| `model` | 任意 | | `train` 返回的模型 |

- `train` 返回模型。模型可以是任意 Python 值，例如权重数组列表。
- 输入形状为 `(M,)` 时，`predict` 返回形状为 `(M,)` 的浮点数组。

## 约束

- 步数预算：最多更新 1500 步，因此 `report` 最多调用 1500 次。
- 目标：在页面未公开随机种子生成的 2000 个新 $x$ 值上，与真实曲线 $\sin(x)$ 的均方误差不超过 0.01。$x$ 范围为 $-\pi$ 到 $\pi$。
- 所有随机数都必须来自 `rng`。相同种子必须生成相同模型。
- 不要修改 `x`、`y` 或其形状。
- `predict` 必须支持形状为 `(1,)` 的单个输入。
- 仅使用 numpy。单次完整提交的时间限制为 20 秒。

## 示例

```python
x, y = make_sine(200, np.random.default_rng(0))
model = train(x, y, np.random.default_rng(1))
predict(model, np.array([0.0, np.pi / 2, -np.pi / 2]))
```

```text
[-0.0165  1.0418 -1.0157]
```

输出舍入到小数点后 4 位。真实值分别是 0、1 和 -1。参考实现使用学习率为 0.01 的 Adam，1500 步后损失从 4.2061 降至 0.0101。这 200 个点仅噪声造成的均方误差就为 0.0106，因此训练损失远低于 0.01 表示网络正在拟合噪声。
