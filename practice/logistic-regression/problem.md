逻辑回归是在线性模型输出上应用 sigmoid 的分类器，输出表示样本属于类别 1 的概率。它通过二元交叉熵损失的梯度下降来训练。所有二分类神经网络也使用相同的损失和梯度。

## 任务

编写四个函数。

1. `sigmoid(z)` 对 `z` 中的每个元素返回 $\sigma(z) = 1 / (1 + e^{-z})$。
2. `compute_loss(X, y, w, b)` 返回模型 $p = \sigma(X w + b)$ 的平均二元交叉熵。
3. `compute_gradients(X, y, w, b)` 返回 `(dw, db)`，即平均损失对 `w` 和 `b` 的梯度。
4. `fit(X, y, learning_rate, epochs)` 用全批次梯度下降训练模型，并返回 `(w, b, loss_history)`。

单个样本的损失为 $-[y \log p + (1 - y) \log(1 - p)]$。令 $z = x \cdot w + b$，同一个损失也可写为 $\log(1 + e^z) - y z$。总损失是 `n` 个样本的均值。

梯度为 $dw = X^T (p - y) / n$，$db = \frac{1}{n} \sum_i (p_i - y_i)$。

`fit` 将 `w` 初始化为零向量，将 `b` 初始化为 `0.0`。每个 epoch 执行以下步骤：

1. 根据当前 `w` 和 `b` 计算 `(dw, db)`。
2. 沿梯度反方向更新 `w` 和 `b` 一步，更新量等于 `learning_rate` 乘以梯度。
3. 将新 `w` 和 `b` 对应的损失追加到 `loss_history`。

$|z|$ 很大时，`np.exp` 会溢出。sigmoid 和损失必须对任意有限的 `z` 都正确。不要截断概率。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `z` | float 数组 | 任意形状 | sigmoid 的输入 |
| `X` | float 数组 | `(n, d)` | 每行是一条样本 |
| `y` | float 数组 | `(n,)` | 每条样本的标签，取值为 0.0 或 1.0 |
| `w` | float 数组 | `(d,)` | 权重 |
| `b` | float | 标量 | 偏置 |
| `learning_rate` | float | 标量 | 学习率步长 |
| `epochs` | int | 标量 | 梯度更新次数，可为 0 |

- `sigmoid` 返回与 `z` 同形状的浮点数组。
- `compute_loss` 返回 Python `float`。
- `compute_gradients` 返回形状为 `(d,)` 的浮点数组和一个 Python `float`。
- `fit` 返回形状为 `(d,)` 的浮点数组、一个 Python `float` 和含 `epochs` 个浮点数的列表。

## 约束

- `1 <= n <= 1000`，且 `1 <= d <= 50`。
- `z` 可以是任意有限浮点数，包括 `1000.0` 和 `-1000.0`。
- 不要修改输入数组。
- 仅使用 numpy。

## 示例

```python
sigmoid(np.array([-2.0, 0.0, 2.0, 1000.0, -1000.0]))
```

```text
[0.11920292 0.5        0.88079708 1.         0.        ]
```

```python
X = np.array([[1.0, 2.0], [2.0, 1.0], [3.0, 4.0], [4.0, 3.0]])
y = np.array([0.0, 0.0, 1.0, 1.0])
w = np.array([0.5, -0.25])
compute_loss(X, y, w, 0.1)
compute_gradients(X, y, w, 0.1)
```

```text
0.6545645625913818
(array([ 0.00990023, -0.07111509]), 0.1663330660944403)
```

```python
fit(X, y, 0.1, 3)
```
