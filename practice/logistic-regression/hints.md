## 提示 1

直接对整个数组运算。`X @ w + b` 会得到全部 `n` 个 logit，再对该向量调用 `sigmoid` 得到概率。

## 提示 2

为了数值稳定，先计算 `e = np.exp(-np.abs(z))`，其值不会大于 1。`z >= 0` 时 sigmoid 为 `1 / (1 + e)`；`z < 0` 时为 `e / (1 + e)`。用 `np.where` 选择公式。

## 提示 3

`np.logaddexp(0.0, z)` 可以在不溢出的情况下计算 $\log(1 + e^z)$。单个样本的损失等于该值减去 `y * z`。

## 提示 4

平均损失对 logit 的梯度是 `(p - y) / n`。根据 `z = X @ w + b` 的链式法则，`w` 的梯度为 `X.T @ (p - y) / n`，`b` 的梯度为 `p - y` 的均值。
