Byte-Pair Encoding（BPE）会根据语料构建分词器词表。它统计相邻符号对出现的次数，把最常见的一对合并为新符号，再重复这一步。最终得到的合并列表就是语言模型读取文本时使用的分词规则。

## 任务

语料是一个字典。每个键是由整数符号 ID 组成的词元组，每个值是该词在语料中的出现次数。

编写四个函数。

1. `count_pairs(units)` 返回相邻符号对 `(a, b)` 及其计数构成的字典。某一对在一个词中出现时，计数增加该词的频次。符号对不能跨越两个词。
2. `best_pair(pairs)` 返回计数最高的符号对。如果最高计数并列，返回按元组顺序最小的一对。例如，`(2, 9)` 小于 `(5, 1)`。`pairs` 为空时返回 `None`。
3. `apply_merge(symbols, pair, new_id)` 返回一个元组，把每次出现的 `pair` 替换成 `new_id`。从左向右扫描。匹配后跳过匹配对的第二个符号，因此两次匹配不会共用同一个符号。
4. `train(units, num_merges, first_id=256)` 最多执行 `num_merges` 次合并。每一步都重新统计符号对，选出最佳符号对，并在每个词中进行合并。合并序号从 0 开始，第 $i$ 次合并使用 ID `first_id + i`。没有符号对，或最高计数小于 2 时提前停止。

`train` 返回元组 `(merges, units)`。`merges` 按训练顺序记录 `(pair, new_id)`。`units` 是合并后的新语料字典。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `units` | 将 int 元组映射到 int 的字典 | 任意数量的词 | 每个词是由符号 ID 组成的元组，对应的值是词频 |
| `pairs` | 将元组映射到 int 的字典 | 任意大小 | 符号对计数，格式与 `count_pairs` 的返回值相同 |
| `symbols` | int 元组 | 长度至少为 0 | 一个词 |
| `pair` | 由两个 int 组成的元组 | `(a, b)` | 要合并的符号对 |
| `new_id` | int | 标量 | 合并后符号的 ID |
| `num_merges` | int | 标量 | 最多合并次数，可以为 0 |
| `first_id` | int | 标量 | 第一次合并使用的 ID |

- `count_pairs` 返回将符号对元组映射到 int 的字典。
- `best_pair` 返回由两个 int 组成的元组，或 `None`。
- `apply_merge` 返回 int 元组。
- `train` 返回元组 `(list of (pair, int), dict)`。第一项是由符号对及其 int 值组成的列表，第二项是字典。

## 约束

- 最多 100 个词，每个词的长度为 0 到 20。词频至少为 1。
- 合并前，语料中不会出现 `new_id` 或从 `first_id` 开始分配的 ID。
- 不要修改输入字典或输入元组。
- 使用 Python 标准库即可；也可以使用 numpy。

## 示例

```python
units = {(1, 2, 3): 5, (1, 2): 3, (2, 3, 2, 3): 2}
count_pairs(units)
```

```text
{(1, 2): 8, (2, 3): 9, (3, 2): 2}
```

```python
apply_merge((7, 7, 7), (7, 7), 300)
```

```text
(300, 7)
```

```python
words = {tuple(b"low"): 5, tuple(b"lower"): 2, tuple(b"newest"): 6, tuple(b"widest"): 3}
train(words, 4)
```

```text
([((101, 115), 256), ((256, 116), 257), ((108, 111), 258), ((258, 119), 259)],
 {(259,): 5, (259, 101, 114): 2, (110, 101, 119, 257): 6, (119, 105, 100, 257): 3})
```

第一步中，`(101, 115)` 和 `(115, 116)` 的计数都是 9。按并列规则选择较小的 `(101, 115)`。
