## 提示 1

先创建形状为 `(max_len, d_model)` 的零数组。`d_model` 为奇数时，最后一列就会保持为 0。

## 提示 2

创建形状为 `(max_len, 1)` 的位置列，以及形状为 `(1, d_model // 2)` 的配对索引行。借助广播生成形状为 `(max_len, d_model // 2)` 的角度表。

## 提示 3

指数为 `2 * i / d_model`。即使 `d_model` 是奇数，分母也仍为 `d_model`。

## 提示 4

将正弦值写入 `0, 2, 4, ...` 列，将余弦值写入 `1, 3, 5, ...` 列。令 `half = d_model // 2`，切片 `0:2 * half:2` 和 `1:2 * half:2` 正好选中这些列。
