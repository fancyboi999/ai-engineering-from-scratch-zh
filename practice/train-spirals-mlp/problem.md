两条互相缠绕的螺旋线很考验小型分类器。直线和简单曲线都无法将它们分开。本题使用小批量数据和 Adam，训练带两个 tanh 隐藏层的网络。检查器随后会在代码从未见过的新点上评估模型。

## 任务

编写两个函数。

1. `train(X, y, rng)` 训练网络并返回训练好的模型。
2. `predict(model, X)` 为 `X` 的每一行返回标签 0 或 1。

数据来自 `support.py` 中的 `make_spirals(n, rng)`。对于 $k \in \{0, 1\}$，第 k 条螺旋臂在角度 $t + k\pi$ 处的半径为 $r(t) = 3t / (4\pi)$，其中 $t$ 从 0 变化到 $4\pi$，因此每条臂转两圈。每个点都带有标准差为 0.08 的高斯噪声。前一半行的标签为 0，后一半为 1。

使用课程中的层：`Linear(2, 24)`、`Tanh`、`Linear(24, 24)`、`Tanh`、`Linear(24, 1)`，再接 sigmoid 输出，使用二元交叉熵损失。使用小批量和 Adam 训练。`X` 的行按标签排序，因此每个小批量都应从打乱后的行顺序中取出。输出概率至少为 0.5 时，标签为 1。

训练时，每次更新都要调用一次 `practice_check` 中的 `report(step, loss)`。第一步为 0。页面用这些值实时绘制损失曲线，检查器会统计调用次数。

## 输入和输出

| 名称 | 类型 | 形状 | 含义 |
|---|---|---|---|
| `X` | 浮点数组 | `(N, 2)` | 训练点 |
| `y` | 整数数组 | `(N,)` | 每个点的标签，为 0 或 1 |
| `rng` | `np.random.Generator` | | 唯一的随机数来源 |
| `model` | 任意 | | `train` 返回的值 |

- `train` 返回模型。模型可以是任意 Python 值，例如权重数组的列表。
- 对形状为 `(M, 2)` 的输入，`predict` 返回形状为 `(M,)` 的整数数组。

## 约束

- 预算：最多更新 1500 步，即最多调用 `report` 1500 次。
- 目标：在 2000 个点组成的留出集上，准确率至少为 0.95。生成该集合的种子不在此页面公开。
- 所有随机数均来自 `rng`，包括打乱顺序。相同种子必须得到相同模型。
- 不得修改 `X` 或 `y`。
- `predict` 必须支持单个点，即形状 `(1, 2)`。
- 只用 NumPy。一次完整提交限时 25 秒。

## 示例

```python
X, y = make_spirals(400, np.random.default_rng(0))
model = train(X, y, np.random.default_rng(1))
predict(model, np.array([[0.75, 0.0], [-0.75, 0.0]]))
```

```text
[1 0]
```

半径为 0.75 时，参数 $t = \pi$。螺旋臂 0 位于角度 $\pi$，螺旋臂 1 位于角度 $2\pi$，因此点 $(0.75, 0)$ 在螺旋臂 1 上。参考解使用大小为 64 的小批量，Adam 学习率为 0.01。它在这 400 个点上的训练准确率达到 1.0。首次报告的损失为 0.7103，1500 步后的最后一次损失为 0.0163。
