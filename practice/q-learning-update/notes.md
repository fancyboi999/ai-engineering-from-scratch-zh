## Off-policy 与 On-policy

Q-learning 使用下一状态所有动作中的最大价值，因此学习的是贪心策略的价值，而 agent 可以用另一种策略探索。这属于 off-policy 方法。SARSA 使用当前策略实际选择的下一动作，因此学习的是 epsilon-greedy 策略本身的价值。在 cliff walking 中，SARSA 会学到更安全的路径，因为它的价值会包含随机动作的代价。

## 为什么终止状态规则很重要

终止状态之后没有未来。如果终止步骤的目标值仍加上 $\gamma \max Q[s']$，目标附近的状态就会继承 agent 永远不会离开的状态价值。这样价值会增长或漂移，策略可能陷入循环。

## 为什么随机数抽取顺序很重要

固定随机种子的运行只有在每次都按相同顺序使用生成器时才可复现。每次调用多抽一个随机数，之后所有动作都会改变。检查会将你的动作与规定抽取顺序的结果比较。
