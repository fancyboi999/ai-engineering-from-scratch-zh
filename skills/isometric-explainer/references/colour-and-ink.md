# 色彩与墨线

这套视觉规则适用于所有机器页面。色彩表示部件的材质，墨线表现形状。动画和状态模型保持不变，只调整绘制方式。实现代码位于 `kit/ink.mjs`；本文说明如何使用。

## 视觉规则

- 舞台背景使用暖纸色：浅色主题为 `#f2efe7`，深色主题为 `#1f1c18`。
- 每种材质使用三种平涂色调：亮、中、暗。面的色调由朝向决定，不使用渐变。
- 工位使用由色板选择的一种主体色。传送架或其他主要运动部件使用第二种颜色，让它容易辨认。
- 使用深海军蓝墨线。每个主要部件外轮廓约 2.6 px，内部边缘 1.2 px，接缝和凹槽约 0.7 px。
- 工作台上的投影使用边缘清晰、偏暖灰色的短阴影，并与投影部件相连。不要用蓝色或紫色，也不要模糊阴影。
- 需要展示内部结构的工位使用玻璃罩：一层浅色染色和一两道白色高光。
- 工位完成时点亮绿色指示灯；失败或留下缺口时点亮红色指示灯。
- 使用带引线的胶囊铭牌，并提供“手绘抖动”滑块。

## 材质

`inkSolid(paths, style)` 取代 `solidSvg` 绘制实体。它会给实体增加 `m-<material>` class，由 CSS 设置该材质的三种色调。

| 材质 | 用途 | 设置方式 |
|---|---|---|
| `mid` | 工位主体色 | `tone: "mid"`，盒体默认值 |
| `hi` | 小型亮色部件，如压头、方块、卡片和纸张 | `tone: "hi"` |
| `lo` | 金属底座、轨道、杆和灯罩 | `tone: "lo"` |
| `board` | 工作台板和关闭状态的部件 | `material: "board"` |
| `ride` | 使用第二种颜色的主要运动部件 | `material: "ride"` |
| `glass` | 罩子和窗户 | 使用 `glassSvg(...)` |
| `lamp` | 状态灯 | 设置 `material: "lamp"`，并在父元素上设置 `data-state="ok"` 或 `"bad"` |

套件会把实体的四级明暗带映射到三种色调。顶面和第 3 级使用亮色，第 2 级和第 1 级使用中间色，第 0 级混合中间色与暗色。暗色只作墨线，不整面使用。

设置关闭的部件时，保留它的形状，并把颜色切换为工作台色。在部件分组上加 `data-off`。不要调整透明度；褪色会透出后面的部件，看起来像玻璃。

## 墨线轮廓

- 对主要实体使用 `silhouetteSvg(points3, P)` 绘制轮廓，并传入一个凸盒的八个角点。若部件有台阶或缺口，对整个部件做 hull 会在缺口处画出错误的直线；应分别为底座和主体绘制轮廓。
- 把轮廓放在部件绘制组的最后一个子元素，避免被自己的表面覆盖。
- 细杆和柱体保留 1.1 px 边线，突出它们的纤细形状。

## 投影

- `castShadowSvg(points3, P, z0)` 将点沿光源方向投射到 `z0` 平面，并填充外轮廓。光源固定，阴影朝向读者并略偏左。
- 把所有阴影放在同一个绘制项中，并设置较大的负偏置，使它们绘制在工作台后、所有台上部件之前。
- 每个主体绘制一片阴影。不要为机械臂等高而细的部件单独投影；它们会远离底座，像另一个物体。
- 工作台本身可以在下方纸面上投影一片阴影。

## 玻璃罩

- `glassSvg(x0, y0, z0, x1, y1, z1, P)` 会绘制染色盒体，并在前侧添加两道高光。
- 设置玻璃罩的深度偏置，让内容先画，再画玻璃，最后画上方的运动部件。

## 状态灯

- 每个工位在顶部放一盏状态灯，并避开机械臂或压头经过的位置。检查 4 倍近景：被压头挡住的灯无法辨认。
- 状态由模型决定。每个节拍将 `pose.lamps[station]` 设为 `ok` 或 `bad`，`draw()` 再复制到 `data-state`。缺口也表示失败，例如未知名称、提升过程拒绝处理，或跳转落在指令中间。

## 铭牌

- `pillSvg([x, y], dx, dy, text, on)` 会绘制奶油色胶囊标签，并用引线连接屏幕坐标。使用 `K.iso` 投影三维锚点，再叠加所属装配的展开偏移，让机器展开时引线仍指向正确部件。
- 锚点应落在实际工作的部件上，而不是主体中间。
- 将铭牌放在机器上方的空白处，交错分成两三行，避免相邻标签碰撞。工位较多时可用两三行胶囊，并根据工位顶面的固定点计算标签高度，逐行错开。
- 目标是 3 到 6 个标签。更长的流水线可以给每个工位都加标签，但必须留出空间。遍历运行中的每个事件帧进行检查。
- 工位活动时，铭牌切换为强调色。
- 将胶囊放入深度排序层之后的 `<g data-pills>` 组。文字、投影锚点或活动状态变化时再重绘。机器展开会移动锚点。
- 页面提供“显示标注”开关，并读取 `?labels=0`。根元素上的 `iso-nolabels` class 会隐藏铭牌。

## 抖动与颜色控件

- `wobbleFilter(id, scale)` 返回位移滤镜。将它应用于深度排序层，而不是铭牌，这样文字保持清晰。
- 范围滑块修改 `[data-wobble]` 元素的 `scale`。值为 0 时移除图层滤镜，降低动画循环开销。
- 色板通过 figure 上的 `--body-l`、`--body-m` 和 `--body-d` 设置三个色调。深色主题下，使用 `blend()` 将色板与深色纸张混合约 0.38，避免颜色刺眼。

## 深色主题

- 保持相同的绘制风格，只使用更深的纸色和更亮的墨线。`INK_CSS` 中的深色主题会替换纸张、墨线、金属、陶瓷、工作台、玻璃和阴影色。
- 检查墨线与最暗主体色之间的对比度，以及胶囊内文字的对比度。
