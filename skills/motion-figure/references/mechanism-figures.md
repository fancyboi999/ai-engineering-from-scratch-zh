# 机制图

机制图是解释一个系统的小型交互面板。读者用一个控件驱动，观察真实内容变化，再阅读图表计算的结论。用于独立页面、README 演示、产品页或文章。课程内优先使用课程图层级。

## 真实名称

展示真实系统的具名部件，不画抽象方框。

| 主题 | 弱表达 | 强表达 |
|---|---|---|
| 上下文窗口 | 变长的灰条 | CONTEXT WINDOW 面板，列出 tool: test output 21k、goal: fix auth 2k 等具名行、颜色图例和右对齐 token 数 |
| 负载均衡器 | 三个框与两条箭头 | 具名客户端、均衡器、副本池、移动数据包，以及可停止的一个副本 |
| 规则文件 | 项目列表 | 真实文件，规则逐条出现，每条注释说明促成该规则的事故 |
| agent 集群 | 一个数字 | agent 方格，其中 N 个运行，其余排队 |

草稿若只有泛化方框，删除并改画真实部件。

## 已否决的图

以下方案曾实现、审阅并删除，不要重做：

1. 无名称的字节条或堆叠灰矩形。
2. 无控件的静态散点图。
3. 对数轴上的直线。指数衰减本来就在该坐标下是直线，图没有增加信息。
4. 无控件的普通方框金字塔。
5. 内容视图更清楚时仍使用聊天气泡。

## 每页一种新机制

维护“机制 / 使用页面”表。构建前读取，选择站内其他页面没用过的形式，完成后添加一行。

可选形式：

| 形式 | 读者操作 |
|---|---|
| 具名行面板 | 选择输入，观察行加载、折叠或移除 |
| 数据包拓扑 | 发送流量，停止部件，观察数据包去向 |
| 生命周期单步器 | 对象逐状态前进，仅启用有效操作 |
| 逐步增长文件 | 规则逐条增加，并说明理由 |
| 并行任务网格 | 设置数量，观察格子从排队到运行到完成 |
| 竞速轨道 | 并排运行两种策略，比较结束时间 |
| 任意步骤崩溃模拟 | 选择进程中止位置，查看保留了什么 |
| 带检查点纸带 | 移动长任务的检查点，查看重做工作量 |
| 内存瓷砖图 | 改尺寸，观察具名区域填充固定格子 |

## 结构

每张机制图按顺序有五部分：

1. 头部：左侧等宽大写标签，两至四词，右侧重播按钮。
2. 说明：一两句话告诉读者做什么、观察什么。
3. 控件：按钮、滑块或开关，一个主控件即可。
4. 主体：具名内容。
5. 结论：根据当前状态计算的一行文字。

`templates/mechanism.html` 提供完整结构。

## 结论

- 用文字表达，颜色不能独自充当结论。
- 使用主体展示的同一组数值计算，不写死结果。
- 每个数都能从图中推导，或引用来源。
- 等宽字体，至少 12.5px。
- 边框色可重复表达结果：绿表示好，红表示坏，文字仍需明确说明。

## 动态预算

| 动作 | 时长 | 缓动 |
|---|---|---|
| 按钮按压 | 120 至 160ms | cubic-bezier(0.23,1,0.32,1) |
| 行或面板显现 | 200 至 300ms | cubic-bezier(0.23,1,0.32,1) |
| 折叠或抽屉 | 380 至 500ms | cubic-bezier(0.23,1,0.32,1) |
| 颜色变化 | 150 至 200ms | ease |

- 只动画 transform 和 opacity，仅在面板开合时动画 max-height。
- 入场不用 ease-in。
- 每个按钮有 `:active { transform: scale(0.96) }`。
- 悬停效果放在 `@media (hover: hover) and (pointer: fine)` 中。
- 列表每项错开 30 至 70ms，只对前八项交错，其余立即显示。
- 所有运动小于 500ms。

## 播放时机

1. 立即渲染首态，运动前即可阅读。
2. 35% 可见时播放一次，IntersectionObserver threshold=0.35，首次运行后断开观察。
3. 提供从首态重播的按钮。
4. 不循环播放机制图。
5. 对打字等高频重复动作，不逐次启动动画。
6. 减少动态效果时立即显示终态，跳过全部过渡。

## 每帧可读

首帧、运行中和终态均需检查：

- 标签不裁剪、不省略。放不下时移到外面并加引线，或使用编号索引。
- 文字不压斜线、条纹或抖点填充。
- 文本框不重叠。
- 图中文字至少 11px，数值与结论至少 12.5px。
- 明暗主题均可读，颜色来自 CSS 变量。

## 小屏幕

- 320px 时面板单列，600px 以下用 grid-template-columns:1fr。
- 320px、390px 页面都没有横向滚动。
- 每个按钮与开关的触摸目标至少 40px。

## 完成前检查

- [ ] 主体展示真实名称和数值，不用 item 1 或 block A。
- [ ] 读者至少可操作一个控件。
- [ ] 结论是文字，改变控件会改变它。
- [ ] 结论数值符合主体数值的算术结果。
- [ ] 进入视口只播放一次，重播有效，没有循环。
- [ ] 减少动态效果时立即显示终态。
- [ ] 无动作超过 500ms，只改变 transform 和 opacity。
- [ ] 1280px、390px 的明暗截图中无标签裁剪与重叠。
- [ ] 点击全部控件时控制台零错误。
- [ ] 机制表中已添加本图一行。
