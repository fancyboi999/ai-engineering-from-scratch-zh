# 抖色场

抖色场通过有序抖色绘制移动像素条带，只用页面的纸张色、强调色和墨色。用于页头或节间，在低开销下提供缓慢运动。完整脚本为 `templates/dither.js`。

## 绘制方法

1. WebGL 片元着色器按四种运动之一，为每个像素计算 0 至 1 的值。
2. 将该值与该位置 8×8 Bayer 矩阵的阈值比较。
3. 值低于 0.7 时，超过阈值用强调色，否则用纸张色。高于 0.7 时，缩放值超过阈值用墨色，否则用强调色。
4. 画布使用元素尺寸的二分之一或三分之一，并设置 image-rendering=pixelated，让每点成为清晰的 2px 或 3px 方块。

## 四种运动

| 模式 | 名称 | 运动 |
|---|---|---|
| 0 | 噪声场 | 分形噪声缓慢向右漂移 |
| 1 | 涟漪 | 圆环从条带右侧附近向外扩散 |
| 2 | 波浪 | 斜向正弦波混合漂移噪声 |
| 3 | 扫描 | 亮边从右向左穿过噪声 |

脚本使用 FNV-1a 对 data-seed 做 hash。hash 对 4 取模选择模式，并偏移噪声。同一种子始终生成同一条带。data-mode 可强制模式。

## 标记

```html
<div class="dither" data-seed="skills" data-label="skills · 15 files" aria-hidden="true"></div>
<script src="dither.js" defer></script>
```

- data-seed：任意字符串，建议页面路径或 slug。
- data-label：可选，左下角小型等宽标签。
- data-mode：可选，0、1、2、3。
- data-px：可选，单点 CSS 像素尺寸，默认 2，600px 以下为 3。
- slim 类将条带高度从 108px 改为 60px。

## 规则

1. 从 CSS 变量读取 bg 纸张色、blueprint 强调色、ink 墨色，默认值分别为 #fafaf5、#3553ff、#1a1a1a。
2. 根元素 data-theme 变化时，用 MutationObserver 更新颜色并重绘。
3. 最多 30fps，两帧间不足 33ms 就跳过。
4. 只在条带可见且标签页未隐藏时绘制，使用 IntersectionObserver 和 visibilitychange。
5. 可悬停设备中，柔和亮点跟随指针。点击启动涟漪，每帧衰减 4%。
6. 减少动态效果时只绘制静态帧，指针、点击、主题或尺寸变化时才重绘。
7. 没有 WebGL 时，用强调色与纸张色绘制静态斜线填充。
8. 着色器编译失败则隐藏条带，页面不显示错误。
9. 条带是装饰，不承载信息，设置 aria-hidden=true。
10. 除带实色背景的小标签外，抖色区域上不放文字。

## 抖色条形

同样的方法可用于图中的条形，给强调色填充加抖色前缘和阶梯式入场。

- 前缘在填充末尾叠加 16 至 24px 的纸张色点阵，密度为 22%、50%、80%，让末端逐步碎成点。
- 入场在填充上盖点阵遮罩，用 steps(4,end) 在约 520ms 内分四步从不透明变为透明。
- 背后灰色轨道可使用 28% 稀疏墨色点阵。
- 可在填充末端放轨道色伪元素，用 8×8 Bayer tile 的 CSS mask 裁剪，避免查色。
- 标签与数值不放在抖色部分上。
- 减少动态效果时直接显示终态，不显示遮罩。
