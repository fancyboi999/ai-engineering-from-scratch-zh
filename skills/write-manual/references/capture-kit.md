# 运行记录工具

手册展示的请求、响应、事件都来自实际运行。记录工具运行程序并写文件，图与 listing 从文件截取，不凭记忆手写。

## 要求

- 工具位于 capture/，输出到 capture/out/。
- 离线运行，不需要网络或密钥。
- 依赖尽量少，完整示例只用 Python 标准库。
- manual.json 用 argv 数组声明两条命令，从手册目录运行：

```json
"capture": {
  "run": ["python3", "capture/run.py"],
  "check": ["python3", "capture/run.py", "--check"],
  "timeoutSeconds": 300
}
```

- run 写入 capture/out/。
- check 写临时目录，与 capture/out/ 比较，有差异则非零退出。
- 审计运行 check，将漂移报告为发现。默认时限 300 秒。

## 确定性输出

检查比较字节，因此两次运行必须生成同样文件。消除变化来源：

| 来源 | 修正 |
|---|---|
| 自动 ID | 固定生成器种子，每次相同 |
| 时间戳 | 固定起点和步长，例如每次增加 250ms |
| 步骤顺序 | 场景固定顺序，逐个运行 |
| 端口 | 绑定 127.0.0.1 的固定端口，在前言列明 |
| 无法固定的值 | 比较前对两份输出做相同屏蔽 |

尽量固定所有值，使检查无需屏蔽，直接比较字节。

## 场景与文件

每种被章节解释的行为一个场景。文件按阅读顺序编号，例如 01-discovery.http、02-reply.http、03-blocking-job.http。每条流单独保存格式化帧，例如 05-streaming.events.json。章节解释客户端时，也记录客户端决策日志。

文件保存完整交互：请求行、重要头、正文。listing 从中截取，读者可打开完整文件。

## 无法离线运行的主题

专有二进制或托管服务无法在无网络 CI 中运行时：

- 在安装固定版本二进制的自有机器上录制。
- check 屏蔽可变字段后比较已保存输出。
- 未安装主题时，check 输出 skipped 和原因，以 0 退出。汇报明确这是跳过，不是通过真实运行。
- 前言列出这些记录及录制机器。
