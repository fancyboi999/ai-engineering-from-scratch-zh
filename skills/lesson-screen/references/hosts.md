# 宿主环境

学习屏幕需要 Node.js 20 或更高版本、本地端口，以及学习者机器上的浏览器。按下列情况处理。

## 默认情况

agent 在学习者的电脑上运行，宿主保留子进程。

1. 运行 `CLI start --open`。
2. `start` 启动独立服务器进程后立即返回。
3. `--open` 打开浏览器。仍需提供 URL，因为打开操作可能失败。

## 命令结束后终止子进程的宿主

若屏幕在第一轮后停止加载，可能是宿主在命令返回时终止了它启动的进程。

1. 使用宿主的后台命令选项运行 `CLI start --foreground --open`。
2. 命令保持运行，先输出启动 JSON。
3. 后续运行 `CLI status` 重新读取 URL。

## 沙箱宿主

沙箱可能禁止本地端口或打开浏览器。启动 JSON 或错误会指出原因。

- 端口被拦截：请学习者允许本命令访问本地网络，或跳过屏幕。
- 浏览器启动被拦截：不带 `--open` 运行 `start`，提供 URL。

## 远程机器

agent 通过 SSH、容器或云端工作区在另一台机器上运行。

- 优先转发端口。运行 `CLI start --port 4777`，请学习者运行 `ssh -L 4777:127.0.0.1:4777 <host>`，再在自己的电脑打开 URL。
- 容器也可以发布端口。使用 `--host 0.0.0.0 --url-host localhost`，发布 4777 端口。
- 仅在学习者要求时绑定 `0.0.0.0`。此时密钥是网络访问的唯一保护。

## 没有终端的宿主

无终端的聊天应用无法运行服务器。改为提供课程页：

```text
https://aieng-zh.cn/lessons/<phase-dir>/<lesson-dir>/
```

课程页展示相同的已注册图表。自制图表需要终端来构建和检查；没有终端时，用文字说明部件与流程。

## 截图

`CLI shot` 需要同一台机器上的 Chrome、Chromium 或 Edge。它检查常见安装路径及 `CHROME_PATH`；`--chrome PATH` 优先于两者。没有浏览器时，命令给出明确错误。应告诉学习者成品尚未做目视检查。

## Windows

PowerShell 与 Command Prompt 使用相同命令。包含空格的路径要加引号。`--open` 使用默认浏览器。

## 离线学习

图表运行时和 3D 库默认从网络加载。离线时，框架显示屏幕文字，并在图表处显示提示。已有构建站点的克隆可用 `--assets local` 从磁盘加载图表运行时。使用 three.js 的自制页面仍需 cdn.jsdelivr.net；无法加载时，以文字展示步骤与部件。
