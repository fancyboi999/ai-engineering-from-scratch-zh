# 认证课程

> 证书应该证明你能完成实际工作，而不是证明你背过题库。

这一部分把公开认证蓝图改造成免费、以构建为主的学习路线。每条路线会组合 AI Engineering from Scratch 的现有课程，以及认证专属课程、实验、诊断和原创模拟考试。

## 项目

| 项目 | 认证 | 从 AI 导师开始 | 网站 |
|---|---|---|---|
| [Claude 认证](claude/README.md) | 2026 年 7 月考试指南公布的四项 Claude 认证 | [Claude 入门](claude/GETTING_STARTED.md) | [Claude 路线](https://aieng-zh.cn/certifications.html) |
| [MCPA 认证](mcpa/README.md) | Model Context Protocol Associate，对齐 MCP 2026-07-28 规范 | [MCPA 入门](mcpa/GETTING_STARTED.md) | [MCPA 路线](https://aieng-zh.cn/certification?id=mcpa-f) |

每份入门指南都适用于 Claude Code、Codex、ChatGPT、Cursor 或其他 agent：导师 skill 会选择路线、每次教授一课、运行实验，并把进度保存在仓库中。

## 规则

- 以公开考试指南确定覆盖范围和权重。
- 以官方产品文档确定当前技术行为。
- 所有课程和练习题都是原创内容。
- 不使用考题泄露内容、机密题目、包过承诺或答案模式技巧。
- 练习结果是课程原始分，不是官方量表分数。
- 动手产物比被动阅读更重要。
