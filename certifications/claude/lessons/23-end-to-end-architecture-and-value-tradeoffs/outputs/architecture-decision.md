# ADR：合同审查模式

## Decision（决策）

选择确定性工作流（workflow）：受理、切分、版本化检索、分析、独立证据审核、修订稿生成和法务
审批。负责人（owner）：法律技术架构团队。

## Candidate Scores（候选方案评分）

增强调用最快，但无法隔离故障。工作流在安全性（safety）、可审计性和可预测的延迟（latency）
方面领先。自适应 agent 只在未建模分支方面领先。多 agent 审核增加了独立性，但没有增加写入权限。

## Hard Gates（硬性门禁）

授权、租户隔离、来源可追溯性和安全性不能与便利性取平均来抵消。任何没有依据的重大结论都会
阻止候选方案通过。

## Failure Paths（故障路径）

检索超时时返回部分证据，不生成修订稿。政策冲突交由法务处理。schema 无效时进行一次针对性修复。
工具中断时转入人工审核队列。回滚（rollback）会恢复先前的索引和工作流版本。

## Rejected Alternatives（被否决的备选方案）

拒绝使用一次巨大的增强调用，因为职责和证据会被压缩在一起。拒绝使用自适应执行 agent，因为
流程已经明确，而且操作需要人工授权。

## Reversal Condition（回退条件）

如果超过 20% 的已接受案件需要安全地发现未建模证据，而且经过评估的 agent 能在不突破成本、
延迟或硬性门禁的前提下提高成功率，就重新考虑工作流。架构负责人批准回退（reversal）。
