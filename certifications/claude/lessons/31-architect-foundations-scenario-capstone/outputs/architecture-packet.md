将每个输入边界以 `input_schema` 录入校验器包。它必须标明每个属性类型，只要求已声明的属性，并将 `additionalProperties` 设为 `false`。无参数工具仍使用闭合对象 schema，其 `properties` 和 `required` 数组为空。

```json
{
  "type": "object",
  "properties": {
    "case_id": {"type": "string"}
  },
  "required": ["case_id"],
  "additionalProperties": false
}
```
